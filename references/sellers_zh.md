## 2. Levanta 账号设置指南：Amazon、Walmart、Shopify 与品牌配置

**Source:** <https://knowledge.levanta.io/articles/3592084624-levanta-amazon-walmart-shopify>

# Levanta 账号设置指南：Amazon、Walmart、Shopify 与品牌配置

Last updated 10 days ago

本指南将带您完成 Levanta 账号设置与管理的核心步骤，从连接亚马逊账号，到配置品牌信息以及管理各平台连接。请按照各个步骤依次操作，确保您的账号已完整配置并可正常开展业务。

## **步骤 1：连接您的亚马逊账号**

在开始之前，您需要先将亚马逊账号连接到 Levanta。这将启用归因追踪、产品同步以及寄样等功能。

  1. 在左侧导航栏中，进入**Settings → Connections**

  2. 在亚马逊标签页下，点击 **\+ Add Amazon Connection**

  3. 按照提示完成亚马逊广告账号授权

连接完成后，您的品牌及产品将自动同步至平台。

**亚马逊连接分为两种类型：**

  * **亚马逊广告（Amazon Ads）** ： 用于亚马逊归因追踪。该连接会同步您的品牌和产品数据，以确保点击与转化在 Levanta 中被正确记录

  * **亚马逊卖家后台（Amazon Selling Partner）** ：如您需要通过平台向创作者发送样品，则必须连接该项。连接成功后，您将在该连接上看到 **Samples Enabled** 标识

⚠ 注意：平台支持连接多个亚马逊账号。如有需要，您可以重复以上步骤添加更多账号。

## **步骤 2：连接 Walmart**

如果您在 Walmart 平台销售商品，可以将您的 Walmart 账号连接至 Levanta，从而在同一后台完成创作者招募、自定义佣金设置以及查看 Walmart 专属报表。

  1. 在左侧导航栏中，进入**Settings → Connections**

  2. 点击 **Walmart** 标签页

  3. 点击**\+ Add Walmart Connection** ，并按照提示完成连接

⚠ 注意：完成 Walmart 账号连接后，请通知您的 CSM，以便其在后台为您完成激活。

## **步骤 3：连接 Shopify**

如您使用 Shopify 店铺，可将其连接至 Levanta，以追踪 DTC（独立站）销售数据，并将您的联盟营销计划扩展至亚马逊以外的渠道。

  1. 在左侧导航栏中，进入 **Settings → Connections**

  2. 点击 **Shopify** 标签页

  3. 点击 **\+ Add Shopify Connection** ，并按照提示完成授权

## **步骤 4：设置品牌资料（Brand Profile）**

您的品牌资料将展示给 Levanta 平台上的创作者。完善且专业的品牌资料有助于提升信任度，并提高优质创作者的合作意愿。

请进入 **Brands** ，选择您的品牌，进入 Brand Profile 编辑页面，并填写以下信息：

  * **品牌简介（Brand Bio）** ：简要介绍您的品牌及所销售的产品

  * **亚马逊店铺链接（Amazon Storefront URL）** ： 方便创作者直接访问您的亚马逊店铺

  * **联系邮箱（Contact Email）** ：创作者可通过该邮箱与您的团队取得联系

  * **条款与条件（Terms and Conditions）** ：填写或链接您的品牌联盟合作条款

## **问题排查：亚马逊店铺 URL 无法显示**

如果您的亚马逊店铺 URL 没有正确显示在 Levanta 品牌资料中，或创作者反馈店铺链接无法开启，问题通常来自亚马逊端。

请依照以下项目逐一检查

**问题**| **检查与解决方法**
---|---
**尚未建立品牌店铺**|  在新增店铺 URL 前，您必须先建立并启用 **Amazon Brand Store** 。建立品牌店铺前，品牌需先加入 **Amazon Brand Registry（品牌备案）** 。完成备案后，请登入 **Amazon Ads** 广告后台，进入 **Brand Store** 建立您的品牌店铺。
**品牌店铺审核中**|  提交 Brand Store 后，Amazon 通常需要 **最长 24 小时** 完成审核。在审核通过并正式发布前，店铺 URL 将无法使用。
**品牌店铺审核未通过**|  若 Brand Store 因审核未通过（Hard Rejection 或 Soft Rejection），店铺链接将无法正常开启。请登入 **Amazon Ads** 后台查看审核原因，完成修改后重新提交审核。
**输入的 URL 不正确**|  请确认您填写至 Levanta 品牌资料中的店铺 URL 与 Amazon 已上线的 Brand Store URL 完全一致。正确格式应类似：amazon.com/stores/YourBrandName/...
**尚未完成 Amazon Brand Registry**|  建立及发布 Brand Store 必须先完成 **Amazon Brand Registry** 。若品牌尚未备案，请前往 [**brandservices.amazon.com**](http://brandservices.amazon.com) 完成申请。

## **如何建立 Amazon Brand Store**

如果您尚未拥有 Amazon Brand Store，请依照以下步骤完成设置。

**1\. 注册 Amazon Brand Registry**

前往 [brandservices.amazon.com](http://brandservices.amazon.com) 完成品牌备案。

注意： 您需要拥有品牌的有效注册商标才能申请

**2\. 登入 Amazon Ads 后台**

登入您的 **Amazon Ads** 广告后台，并进入 **Brand Store（品牌店铺）** 。

**3\. 建立品牌店铺**

使用 Amazon 提供的 **Store Builder** （品牌店铺建立工具）设计您的店铺。

您可以：

  * 使用预设模板快速建立页面

  * 透过拖放方式编辑页面内容

  * 新增商品

  * 上传品牌图片

  * 编辑品牌介绍及其他品牌内容

**4\. 提交审核**

完成店铺设计后，提交审核。

Amazon 一般会在 **24 小时内** 完成审核。

**5\. 将店铺 URL 填入 Levanta**

待 Brand Store 审核通过并正式上线后：

  1. 复制您的 Amazon Storefront URL。

  2. 回到 Levanta。

  3. 前往 **Brand Profile（品牌资料）** 。

  4. 将链接贴至 **Amazon Storefront URL** 栏位。

完成后，创作者即可正常访问您的品牌店铺。

## **步骤 5：上传品牌素材**

Levanta 提供 **Manage Brand Assets** 功能，允许您在平台内直接上传和管理品牌素材。这些素材将展示在面向创作者的页面中，包括创作者发现页、品牌推荐位以及品牌化创作者注册流程中。

进入您的 **Brand Profile** ，点击页面右上角的 **Manage Brand Assets** 按钮，即可打开素材管理面板，并上传以下内容：

  * **Logo 文件（彩色，用于白色背景）** ：用于创作者页面的浅色背景展示。请上传正方形的 SVG 或 PNG 文件（最大 2MB）

  * **Logo 文件（白色，用于深色背景）** ：用于深色背景展示。建议使用带透明背景的 PNG，或上传正方形 SVG / PNG 文件（最大 2MB）

  * **品牌水印图（Lifestyle watermark）** ：作为水印显示在创作者发现页面中白色 Logo 背后。请上传 SVG 或 PNG 文件（最大 2MB）

上传完成后，您可以点击 **Preview** 预览展示效果，或使用 **Copy to other Brands** 功能，将同一套素材一键应用至您账号下的其他品牌，大幅提升多品牌管理效率。

⚠ 注意：品牌素材将用于 Levanta 创作者端的品牌推荐展示以及品牌化创作者注册流程。保持素材的最新状态有助于提升您在平台中的品牌曝光度。

## **步骤 6：管理多平台（Marketplace）**

Levanta 支持在一个账号下同时管理多个电商平台的联盟营销项目，包括亚马逊（全球各站点）、Walmart 以及 Shopify。

您可以通过后台的 marketplace 切换器，在不同地区或平台之间进行切换。

在 **Payments** 中，您可以查看所有已连接平台的统一发票视图，无论当前选择的是哪个平台。

如果您只想查看某一个站点的账单，无需退出当前的统一视图。您只需进入 Payments（付款） 页面，点击 Filters（筛选），然后在 Marketplace（站点） 下拉菜单中选择需要查看的市场。

筛选后，账单列表将仅显示所选市场的账单，且不会影响 Levanta 其他页面当前显示的市场数据。

### **重要说明**

  * Levanta 中的各个模块（如 Dashboard、Products、Brands 等）都会根据您当前选择的市场显示对应数据。

  * Payments（付款）模块是例外。 无论顶部的市场切换器当前选择哪个市场，Payments 页面都会统一显示所有市场的账单。如果您只想查看某一个市场的账单，请使用 Payments 页面中的 Filters（筛选） 功能，并选择相应的市场。

  * 根据您当前使用的套餐，如需访问更多 Amazon 全球市场或使用 Walmart 相关功能，您可能需要升级套餐。

# Levanta 卖家入门清单：账号搭建指南

Last updated 10 days ago

本指南将带您完成在 Levanta 上从账号创建到项目上线的完整流程，包括创作者招募、活动开展以及后续优化。请按照各阶段顺序操作，以确保顺利启动并高效运行您的联盟营销项目。

## **阶段 1：账号注册与团队设置**

在开始其他操作前，请先完成账号及支付设置。

  * 在 [_app.levanta.io_](http://app.levanta.io) 注册 Levanta 账号

  * 在账户的 billing 设置中，通过 [_Stripe_](https://knowledge.levanta.io/articles/4331155621-stripe-sop) 添加支付方式

  * 选择您偏好的支付方式（如信用卡、银行转账等）

  * 开启自动扣费（Auto-Billing）（可选但推荐），以避免项目运行过程中出现中断

## **阶段 2：账号连接**

### ** _亚马逊账户链接_**

连接亚马逊账号是实现销售追踪并启用核心功能的关键步骤。

  * 连接您的亚马逊广告账号（Amazon Ads Connection），以启用亚马逊归因追踪。这是确保点击与转化数据在 Levanta 中正常显示的必要条件

  * 如您计划使用产品寄样功能，请添加亚马逊卖家后台（Amazon Selling Partner）连接路径：Seller Central → Settings → Connections → 选择最后一个选项）

⚠ 注意：如需通过 Levanta 向创作者发送产品样品，必须完成亚马逊卖家后台连接。

### ** _沃尔玛账号链接_**

  * 前往 **Settings → Connections → Walmart** 标签页。

  * 点击 **\+ Add Walmart Connection** ，并按照页面提示完成授权，连接您的 **Walmart Marketplace** 或 **Supplier** 账户。

  * 如果您使用的是 **Launch Plan** ，或需要后台启用 Walmart 功能，请联系您的客户成功经理（CSM），或发送邮件至 [cs@levanta.io](mailto:cs@levanta.io) 完成设置。

⚠ 注意： 连接 Walmart 后，您可以在同一个仪表板中统一查看 Amazon、Shopify 和 Walmart 的业绩数据。

### ** _Shopify账号链接_**

  * 前往 **Settings → Connections → Shopify** 标签页。

  * 点击 **\+ Add Shopify Connection** ，系统将跳转至 **Shopify App Store** 中的 Levanta 应用页面。

  * 登录您的 Shopify 账户，并点击 **Install（安装）** 完成连接。

## **阶段 3：品牌资料与素材设置**

您的品牌资料是创作者在平台上了解您的第一入口。完善且专业的展示有助于建立信任，并提升优质创作者的合作意愿。

请完善您的品牌页面，填写以下信息（这些内容将对创作者可见）：

  * 品牌简介（Brand bio）

  * 联系方式（Contact details）

  * 亚马逊店铺链接（Amazon Storefront URL）

  * 邮箱（Email）

  * 条款与条件（Terms and conditions）

请使用 **Manage Brand Assets** 功能上传您的品牌素材。在品牌资料页面中点击 **Manage Brand Assets** 按钮，即可打开素材管理面板。在此您可以上传以下内容：

  * **Logo 文件（彩色，用于白色背景）** ：用于 Levanta 创作者端页面及发现页展示。请上传正方形 SVG 或 PNG 文件（最大 2MB）

  * **Logo 文件（白色，用于深色背景）** ：用于深色背景展示。建议使用带透明背景的 PNG，或上传正方形 SVG / PNG 文件（最大 2MB）

  * **品牌水印图（Lifestyle watermark）** ：用于创作者发现页面中，作为白色 Logo 背后的水印图（支持 SVG 或 PNG）

上传完成后，可使用 **Copy to other Brands** 功能，将同一套素材一键应用至多个品牌。如您在同一账号下管理多个品牌，这将大幅提升操作效率。

⚠ 注意：品牌素材将用于 Levanta 创作者端的品牌推荐展示以及品牌化创作者注册流程。定时更新素材有助于提升您在平台中的品牌曝光度。

## **阶段 4：产品目录与佣金设置**

完成品牌激活并设置佣金结构，以吸引创作者参与推广。

  * [ _管理品牌与产品_](https://knowledge.levanta.io/articles/6028881294)：进入 **Brands → 选择您的品牌 → Activate** ，查看相关条款并确认地区

  * 开启创作者申请自动通过（推荐）：减少审核流程阻力，加快创作者增长速度

  * 设置公开佣金比例：平台平均水平约为 20%

  * 为高价值创作者设置私有佣金：平台平均水平约为 25%

  * 激活您的产品，使创作者能够生成归因链接并开始推广

## **阶段 5：创作者招募与 Social Discovery**

完成项目设置后，接下来就可以开始拓展您的创作者合作网络。

  * 浏览 Creator Directory（创作者目录），寻找与您的品牌品类及目标受众相匹配的创作者。

  * 批量发送合作邀请 — 前往 Directory → 选择创作者 → Bulk Actions（批量操作）→ Send Partnership Invites（发送合作邀请）。建议在邀请中添加个性化信息，以提高创作者的接受率。

  * 创建 Creator Groups（创作者分组），根据合作伙伴类型进行分类，方便后续管理及开展更有针对性的合作邀约。

  * 分享品牌专属创作者注册页面: 前往 Creators → Applications → Branded Creator Sign-Up Page 获取专属注册链接。您可以将该链接分享给创作者，让他们快速注册并申请加入您的合作项目。

  * 使用 Social Discovery，直接从 TikTok 和 Meta搜索并招募创作者，即使对方尚未加入 Levanta 也可以进行邀约。前往 Creators → Social Discovery 即可使用。

💡**提示：** Social Discovery 的创作者搜索范围更广，不仅限于 Levanta 平台内的创作者。相比之下，创作者市场仅展示已经加入 Levanta 的创作者。

## **阶段 6：创作者激活与沟通**

创作者通过审核只是开始，持续且及时的沟通才是实现转化的关键。

  * 如未开启自动通过，请每日审核并处理创作者申请

  * 通过 [**_Messaging_**](https://knowledge.levanta.io/articles/3184117881-)**** 工具向每位新通过的创作者发送欢迎消息，建议包含：主推产品、佣金比例、归因周期、媒体资料链接以及联系人信息

  * 发布品牌公告以同步重要信息：进入 **Brands → Announcements → Create Announcement** （每 7 天最多 2 条）

  * 如有需要，可导出已合作创作者名单用于站外邮件触达：进入 **Creators → Active → Export CSV** ，导出文件包含创作者邮箱

  * 为高价值创作者设置私有佣金，提供额外激励，提升其优先推广意愿

## **阶段 7：活动与促销**

通过策略性活动与投放，进一步提升整体表现与转化效果。

  1. [** _Deals_**](https://knowledge.levanta.io/articles/1033728459-levanta-deals)****

  3. **Creator Connections（CC）集成**

     * 在 Levanta 中创建 CC 活动：进入 **CC → Campaigns → Create**

# 什么是 Levanta for Shopify？

Last updated 10 days ago

Levanta for Shopify 是一项原生集成功能，允许品牌在 Levanta 平台内管理其 Shopify 独立站的联盟营销与创作者合作项目，同时与现有的 Amazon 和 Walmart 项目统一管理。

通过 Levanta，品牌可以在 Amazon、Walmart 以及 Shopify 三大渠道中，从同一个系统统一管理联盟与创作者项目，实现数据整合、效果追踪与佣金结算的一体化操作。

## **适用对象**

Levanta for Shopify 适合以下类型的品牌：

  * 同时经营 Amazon、Walmart 和 Shopify 的品牌方。希望通过一个平台统一管理创作者合作、业绩追踪与佣金发放，提高运营效率。

  * DTC（Direct-to-Consumer，直面消费者）品牌。希望寻找传统联盟平台之外的更现代化解决方案，采用以创作者为核心、以效果为导向的合作模式。

## **为什么选择 Shopify？**

Shopify 是当前 DTC（直面消费者）电商的核心平台，拥有数百万活跃店铺。然而，在 Shopify 生态系统中，联盟营销工具仍然存在分散、老旧且难以管理的问题。

Levanta 的 Shopify 集成功能可以帮助品牌实现：

  * 提升利润空间与自主掌控能力

  * 降低运营复杂度

  * 在所有销售渠道中运行同一个创作者计划

  * 用现代化平台替代割裂、过时的传统联盟工具

## **Levanta for Shopify 解决的问题**

### **企业级 / 多渠道品牌面临的挑战**

  * 成本压力：团队更加精简、利润空间收缩，品牌需要更高效、以效果为导向的营销方式。

  * 项目割裂：品牌在 Amazon、Walmart 和 DTC 渠道依赖多个不同工具。

  * 传统联盟平台过时：老旧工具是为传统联盟营销模式设计的，并不适配现代创作者合作模式。

  * 绩效可视化有限：难以衡量跨渠道的增量收入以及品牌带动效应。

### **单渠道（以 Shopify 为核心）面临的挑战**

  * 创作者营销启动成本高，且耗时较长。

  * 招募、签约及追踪合作伙伴仍以人工操作为主。

  * 传统联盟工具操作繁琐、系统老旧。

  * 难以清晰判断哪些合作真正带来了实际效果。

## 核心优**势**

**统一运行创作者计划**

在同一个平台上管理 Amazon、Walmart 和 Shopify 的创作者与联盟伙伴，降低成本与运营负担。

**更快速激活创作者合作**

利用 AI 驱动的创作者发现工具、社交监听以及产品寄样功能，更高效地招募并启动合作。

**通过跨渠道数据优化营销投入**

实时衡量创作者在各大电商平台与 DTC 渠道的表现及增量影响，优化预算分配。

**简化运营流程**

在一个平台内完成佣金设置、样品寄送、业绩追踪与佣金结算管理。

**获得清晰的绩效可视化**

无需手动整理报表，即可查看跨渠道的 ROI、内容表现及佣金支付情况。

## **核心平台功能**

### **发现与招募创作者**

通过 Levanta AI 驱动的创作者市场（Creator Marketplace），寻找高绩效创作者。

### **产品寄样与赠送**

从申请到发货，全流程自动化管理产品寄样。如需了解更多，请查看我们的 [_Managing Product Samples in Levanta_](https://knowledge.levanta.io/articles/8755198258-how-to-send-samples-to-creators) 指南。

### **付费合作**

在同一个平台内协商并管理固定费用的创作者合作。如需了解更多功能详情，请查看[ _付费推广合作入门指南（卖家版）_](https://knowledge.levanta.io/articles/5570172538-)指南。

### **社交监听**

识别已经在讨论您的品牌或产品的创作者。

### **报告与数据分析**

实时跟踪 Shopify、亚马逊和沃尔玛上的联盟与创作者表现，以及品牌报告（Brand Reports）和产品报告（Product Reports）。

### **支付与税务**

只需进行一次付款。Levanta 将负责资金分发及税务文件处理。

### **原生集成**

一键集成 Amazon、Walmart 和 Shopify。

我们建议您在同步完成后，检查相关合作关系，确保佣金结构和合作条款与您的 Shopify 运营策略保持一致。

## **总结**

Levanta for Shopify 将 DTC（直面消费者）创作者营销整合至与 Amazon 和 Walmart 相同的生态体系中，使您的品牌能够：

  * 整合工具，降低成本

  * 更快速扩大创作者合作规模

  * 跨所有渠道衡量营销表现

  * 推动增量收入与品牌增长

此次集成是迈向统一化、以绩效为导向的现代电商品牌创作者经济的重要一步。

# 创作者分组：高效管理、组织和细分创作者合作伙伴

Last updated 10 days ago

## **创作者分组的使用方式与作用**

创作者分组是 Levanta 中的一项强大功能，可帮助您将合作的创作者按不同维度进行分组，以实现更高效的管理、沟通以及激励策略执行。无论您是按照内容领域、表现层级、流量来源还是内容类型进行划分，创作者分组都能帮助您在规模化运营中进行更精准的策略执行，而无需逐一管理每一位创作者。

### **如何访问创作者分组**

在左侧导航栏中，进入**Creators → Groups** ，即可访问您的创作者分组管理页面。在该页面中，您可以查看所有已创建的分组、查看每个分组的成员数量，并根据需要对分组进行管理或删除

## **如何创建创作者分组**

  1. 在左侧导航栏中，进入**Creators → Groups**

  2. 点击右上角的**Create Group**

  3. 输入**Group Name（** 建议使用清晰且具有描述性的名称，例如：“高表现创作者”、“折扣平台”、“节日活动合作伙伴”）

  4. 添加分组描述**Description** ，帮助团队理解该分组的用途

  5. 点击**Create New Group** 完成创建

## **如何将创作者添加到分组**

根据您在平台中的操作位置不同，Levanta 提供三种方式将创作者添加到分组：

**方式一：从分组页面添加**
打开任意已创建的分组，点击Quick Add Members，即可在该分组页面中搜索并直接添加创作者

**方式二：通过分组管理组件（Group Manager Widget）添加**
分组管理组件在平台多个位置均可使用，包括创作者发现页（Creator discovery）、创作者列表页（Creator catalog）以及单个创作者详情页。在任意创作者卡片上点击该组件，即可将其加入已有分组，或现场创建新分组。带有绿色勾选标记的分组表示该创作者已在该分组中。

**方式三：从创作者库（Creator Directory）批量添加**
在 Creator Directory 中浏览并选择多个创作者，然后通过 Bulk Actions（批量操作）一次性将其加入分组——适用于从零开始快速建立新的分组。

## **如何从创作者分组中移除成员**

  1. 在左侧导航栏中，进入**Creators → Groups**

  2. 点击对应的**Group Name** ，进入该分组页面

  3. 找到需要移除的创作者

  4. 在 **Actions** 操作栏中，点击创作者名称旁的 **Remove Member** 图标（红色按钮）

创作者将立即从该分组中移除。此操作不会影响双方的合作关系或任何正在进行的佣金，仅会将其从当前分组中移除。

## **创作者分组使用建议**

  * 按类型分组：可将折扣平台、内容媒体、社交创作者以及细分领域创作者分别建立独立分组，以便针对不同类型制定对应的沟通方式和佣金策略

  * 用于设置专属佣金： 无需逐个创作者设置佣金，可将高表现创作者集中到一个分组，并一次性为该分组设置专属佣金

  * 建立季节性分组： 在大促或重要活动前，为活跃创作者建立专属分组，方便快速触达并发送独家活动或优惠

  * 保持分组命名清晰：如果是团队协作，清晰的分组名称和描述可以帮助团队成员快速理解每个分组的用途

# 理解 Levanta 中的不同创作者类型

Last updated 4 months ago

## **如何构建高效的创作者合作策略**

为了实现增量销售并提升品牌曝光，建议与多种类型的创作者建立合作关系。不同类型的创作者在用户购买路径中的作用各不相同，从“种草”到“转化”，多元化的合作策略能够帮助品牌覆盖整个转化漏斗的各个阶段。

在 Levanta 平台上，所有创作者均经过筛选与审核，以确保其内容质量、可信度以及符合平台标准。以下是常见的创作者类型及其对品牌的价值：

## 📱**社交型创作者（内容创作者）**

在各类社交平台（如 Instagram、Facebook、YouTube、TikTok 等）建立个人影响力的创作者，包括博主、视频创作者以及拥有个人网站的内容创作者。

他们通常通过更具个人风格和真实感的内容进行推广。

  * 以真实内容展示产品，覆盖广泛受众

  * 通过个人推荐建立信任感和用户认同

  * 帮助品牌触达尚未主动搜索产品的潜在用户（种草阶段）

## 📰**内容媒体 / Publisher（编辑型媒体）**

具备媒体属性的内容平台或网站，通常遵循一定的编辑标准，而非以社交内容为主。

这类合作方擅长输出深度评测、对比文章、榜单推荐以及使用指南等内容。

  * 利用 SEO、订阅用户及内容沉淀，实现长期曝光

  * 适合打造高转化的长尾内容（evergreen content）

  * 通过第三方评测提升品牌公信力

## 🛠**联盟网络（Affiliate Network）**

连接品牌与多个推广渠道及创作者的平台，帮助品牌在不同内容和电商场景中实现商品曝光与转化。

  * 提升转化追踪与归因能力

  * 通过单一合作拓展多个推广渠道

  * 提供工具支持，降低创作者推广门槛

## 📈**媒体买量方（付费流量）**

通过投放广告（如搜索广告、Facebook Ads 等）来获取流量并推广产品的营销方。

  * 帮助品牌进入高转化的广告流量位

  * 快速放大流量规模，并具备可衡量的 ROI

  * 通常会根据表现要求更高的佣金比例

## 🏷**优惠/折扣平台（Deal Site）**

以优惠信息、折扣聚合为主的平台，并非社交媒体账号，主要面向价格敏感型用户。

  * 有效带来首次购买用户（拉新）

  * 在大促、活动期间显著提升销量

  * 覆盖强购买意图用户，加速转化

## 🎁**返利/会员平台（Loyalty Platform）**

提供返现、积分或奖励机制的平台，用户通过消费获得额外收益。

  * 提高复购率与用户生命周期价值（LTV）

  * 通过奖励机制提升客单价

  * 吸引本身已有购买意图的用户群体

  * 通过平台入口促进品牌曝光与转化

## **构建多元化的创作者组合**

单一类型的创作者难以最大化整体效果。更有效的策略是组合多种类型协同运作：

  * 社交创作者 + 内容媒体：负责品牌曝光与种草

  * 联盟网络：帮助拓展渠道覆盖

  * 媒体买量方 + 折扣平台 + 返利平台：承接转化并放大销售

通过多元合作，可以降低对单一渠道的依赖，同时在用户购买路径的不同阶段实现持续触达与转化。

## 9. 创作者沟通指南：站内消息与品牌公告的区别

# 创作者沟通指南：站内消息与品牌公告的区别

Last updated 10 days ago

## **概览**

Levanta 提供两种主要的创作者沟通方式：站内消息**In-App Messaging** 和品牌公告 **Brand Announcements** 。两者都可帮助您与合作创作者保持联系，但在创作者管理策略中各自承担不同角色。合理使用这两种工具，可确保信息以最合适的方式触达创作者。

## **1\. 品牌公告**

**适用于大范围通知**

品牌公告是向所有已合作创作者传达品牌更新的主要工具。它提供统一的沟通入口，并减少创作者收件箱的干扰，从而确保重要信息能够获得更高的曝光与关注。

**品牌公告的适用场景：**

  * **新品发布** ：展示新上架产品，帮助创作者快速开始推广

  * **季节性活动** ：发布黑五、网一、Prime Day 等限时促销活动信息

  * **品牌动态** ：向所有合作创作者同步品牌资料、更新或新的合作机会

**核心优势：**

  * **高曝光率** ：公告将展示在品牌页面、创作者的公告专区以及每日汇总邮件中，确保信息不被忽略

  * **丰富内容支持** ：可在公告中标记指定产品，并附加文件，提升信息的完整性与可执行性

  * **高效沟通** ：无需逐一发送消息，即可一次性触达所有合作创作者，提升沟通效率

## **如何创建品牌公告**

在 **Brands → Announcements** 页面中，按照以下步骤操作：

  1. 点击 **Create new announcement**

  2. 选择您要发布公告的品牌

  3. 选择接收对象：

  * 所有已合作的创作者

  * 指定的创作者分组

  * 所有已合作创作者（排除特定创作者）

  4. 填写公告内容及信息

  5. 点击 **Publish** 发布公告

⚠注意：**每个品牌每 7 天最多可发送 2 条公告**

## **2\. 站内消息**

适用于精准触达与一对一沟通

消息工具更适合用于直接的双向沟通和个性化触达。当沟通需要更有针对性、更加个人化，而非群发通知时，建议使用该功能。

**品牌公告的适用场景：**

  * **个性化引导：** 向新通过审核的创作者发送专属欢迎消息，并提供明确的操作指引

  * **专属优惠沟通** ：发送仅限个别创作者使用的折扣码或激励方案，不对全部合作方公开

  * **关系维护** ： 进行一对一沟通，讨论内容策略、寄样需求或表现反馈

  * **定向分组沟通** ：向特定创作者分组（如“高表现创作者”或“科技评测类”）发送更有针对性的消息

**推荐做法：**

  * **使用消息模板** ：模板可帮助保持沟通内容的一致性，同时支持快速个性化调整

  * **检查身份设置：** 发送前请确认当前使用的身份（Brand View 或 Seller View），确保创作者看到正确的发送方信息

## **如何选择合适的沟通工具？**

功能| 适用场景| 展示位置
---|---|---
**品牌公告**|  广泛通知：新品发布、促销活动、品牌更新| 品牌页面、公告标签页及每日邮件
**站内消息**|  定向沟通：欢迎消息、一对一支持、专属优惠| 创作者收件箱 / 对话框

##  💡 **专业建议**

在黑五等大型促销活动中，建议先使用**品牌公告** ，确保所有合作伙伴都能看到核心优惠信息。随后，再通过**消息工具** 针对表现优秀的创作者进行跟进，提供专属激励或更高佣金，从而在不打扰所有人的情况下，为核心合作伙伴打造更有价值的合作体验。

# 为创作者创建链接：快速生成联盟推广链接

Last updated 10 days ago

作为卖家，您现在可以直接在产品详情页中，为创作者生成 Levanta 联盟推广链接。这样您无需等待创作者自行创建链接，即可快速将可直接使用的追踪链接分享给合作创作者。

## **如何为创作者创建链接**

  1. 进入 **Products** ，选择您希望生成链接的产品。

  2. 在商品详情页，点击 **Actions（操作） > Create Link for Creator（为创作者创建链接）**

  3. 右侧将弹出侧边栏。在列表中搜索或选择您希望生成链接的创作者。

  4. 选择创作者后，系统将自动生成推广链接。点击 **Copy your link** 即可复制链接。

**默认支持移动端优化：** 为创作者生成的链接默认已针对移动设备进行优化，可将买家直接引导至亚马逊 App，带来更顺畅的购买体验。这也是大多数推广内容推荐使用的链接形式。

### **小贴士**

需要为其他创作者生成链接？点击当前已选创作者名称旁边的 **X** 按钮即可取消选择，并返回创作者列表，无需关闭并重新打开侧边栏。

## **与创作者分享链接**

复制链接后，您可以通过 Levanta 的消息功能直接发送给创作者。创作者也可以在自己的 Levanta 后台中，通过以下路径查看该链接：**Tracking → Product Links**

**注意：** 如果创作者此前已经为同一产品生成过链接，Levanta 将返回相同的链接，因此不会产生重复或冲突的链接。

## **常见问题**

### **我可以为任何创作者生成链接吗？**

是的，您可以为所有与您的品牌建立有效合作关系的创作者生成链接。

### **如果创作者已经为该产品创建过链接怎么办？**

无需担心。Levanta 会返回该创作者已拥有的相同链接，不会重复生成新的链接。

### **创作者在哪里查看这些链接？**

创作者可以在 Levanta 后台通过以下路径查看所有为其生成的链接：**Tracking → Product Links**

### **生成的链接是否支持移动端优化？**

是的。通过 **Create Link for Creator** 创建的链接默认已针对移动设备优化，可将买家直接引导至亚马逊 App。

# Social Discovery 入门指南

Last updated 10 days ago

Social Discovery 可将品牌的社交媒体账号连接到 Levanta，让您无需离开平台即可轻松发现并招募 Instagram、Facebook和 Tiktok 上的优质创作者。

与其在多个工具之间来回切换并手动管理创作者招募流程，Social Discovery 将创作者搜索功能直接整合到 Levanta 后台，不仅覆盖已加入 Levanta 的创作者，也涵盖平台外的潜在合作伙伴。

### **什么是 Social Discovery？**

Social Discovery 是 Levanta 推出的 AI 驱动创作者搜索工具。品牌可通过自然语言搜索，在 TikTok、Instagram 和 Facebook 上寻找并招募合适的创作者。

您可以直接在 Levanta 中查看创作者数据（如粉丝数、互动率、GMV 等），并一键发送合作邀请，无需离开平台即可完成招募流程。

### **核心功能**

  * **AI 智能搜索** ：使用自然语言搜索 TikTok、Instagram 和 Facebook 创作者

  * **创作者数据概览** ：快速查看粉丝数量、互动率、受众数据及内容表现

  * **创作者招募** ：邀请已加入 Levanta 或尚未加入 Levanta 的创作者参与您的项目

### **为什么使用 Social Discovery？**

许多品牌在拓展创作者合作项目时，通常会遇到以下挑战：

  * 难以在 Levanta 现有创作者网络之外找到合适的合作对象

  * 社交媒体上的沟通流程与联盟营销项目没有形成有效连接

  * 需要不断切换多个平台来搜索、联系和管理创作者，耗费大量时间

Social Discovery 可帮助解决以上问题。您可以在 Instagram、Facebook和Tiktok 上高效发现并招募创作者，将社交媒体运营与联盟营销工作流整合到同一个平台中，并统一管理跨平台创作者合作关系。

### **如何连接您的社交媒体账号**

开始使用前，请先完成社交媒体账号连接：

  1. 在左侧导航栏点击 **Creators（创作者）**

  2. 选择 **Social Discovery**

  3. 点击右上角的 **Connect Social Accounts（连接社交账号）**

  4. 按照提示完成账号验证及授权

⚠**提示：** Instagram 必须连接至 Meta Business商业账号。TikTok 则必须连接 TikTok Business（企业）账号，个人账号无法使用。您可以为不同品牌连接多个社交媒体账号。

### **使用流程**

完成社交媒体账号连接后，您可以按照以下步骤开始使用 Social Discovery。

**第一步：选择品牌**

通过 Social Discovery 页面顶部的品牌选择器，选择您要招募创作者的品牌。您可以为不同品牌连接多个社交媒体账号。

**第二步：搜索创作者**

在 Meta 与 Tiktok 标签页之间切换，搜索对应平台的创作者。

您可以使用 AI 搜索框，通过自然语言描述目标创作者。例如：“美国地区推广美妆产品的创作者”

系统会根据您的搜索内容自动推荐相关筛选条件，帮助您快速缩小搜索范围。

**第三步：评估并邀请创作者**

您可以在创作者资料卡中：

  * 查看内容表现、粉丝数量、互动率及受众数据

  * 判断创作者是否符合您的品牌定位

  * 复制邀请文案或使用预设邀请模板。点击 **Send（发送）** 后，系统将打开对应社交平台（**Facebook、Instagram 或 TikTok** ）的私信页面，完成合作邀请。

创作者资料卡还会显示其当前状态，帮助您快速了解下一步操作：

  * **Send Partnership Invite（发送合作邀请）** ：创作者已加入 Levanta，可直接发送合作邀请。

  * **Invite（邀请）** ：创作者尚未加入 Levanta，可邀请其加入 Levanta 后再展开合作。

**第四步：维护合作关系**

成功建立联系后，您可以：

  * 与创作者分享邀请注册链接

  * 引导创作者加入 Levanta 并参与您的项目

  * 发送产品样品

  * 在 Levanta 后台持续追踪创作者表现

### **创作者筛选条件**

您可以使用筛选器快速找到符合品牌需求的创作者。支持的筛选条件包括：

  * **国家/地区（Country）** ：按创作者所在地筛选

  * **粉丝数量（Follower Count）** ：按受众规模筛选

  * **互动率（Interaction Rate）** ：寻找高互动创作者

  * **兴趣领域（Interests）** ：匹配产品品类与创作者内容领域

  * **受众画像（Creator Audience）** ：根据创作者粉丝群体的人口统计特征进行筛选

使用 AI 搜索栏时，系统也会自动应用筛选条件。平台会解读您的自然语言查询，并一键推荐相关筛选条件供您使用。

### **常见问题**

**Social Discovery 支持哪些社交平台？**

目前，Social Discovery 支持 Instagram、Facebook 以及 TikTok Business（企业）账号。

其中 Instagram 必须通过 Meta Business（Meta 商业）账号 完成连接。TikTok 必须连接 TikTok Business（企业）账号，暂不支持个人账号。

**我可以发现尚未加入 Levanta 的创作者吗？**

可以。Social Discovery 专门设计用于帮助品牌触达 Levanta 平台外的创作者，方便您直接从社交媒体平台招募合作伙伴。

**我可以为多个品牌连接社交账号吗？**

可以。您可以连接多个社交媒体账号，并分别分配给不同品牌使用。

**连接社交媒体账号会影响现有 Levanta 项目吗？**

不会。连接社交媒体账号属于新增功能，不会影响或中断您现有的联盟营销项目、Creator Connections 活动、Paid Placements 或其他正在运行的 Levanta 工作流程。

# 了解创作者等级（卖家指南）

Last updated 6 months ago

## **什么是创作者等级 Creator Tiers？**

在 Levanta 平台上，每位创作者都会对应一个等级。这个等级可以帮助您快速判断创作者的经验水平、合作成熟度，以及是否适合您的推广目标。这些等级会显示在创作者主页中，方便您在筛选时做参考。

## **四个等级概览**

### **Starter**

新加入平台的潜力创作者。这类创作者刚起步，但通常积极、主动，愿意尝试新合作方式。

**对卖家意味着什么？**

  * 有较强的主动性，希望建立自己的影响力

  * 对新的合作机会反应积极

  * 在合作方式上通常比较灵活，愿意尝试新的合作方式

  * 适合：测试型推广、建立长期合作关系、发掘细分市场潜力创作者

**您可以预期：**

  * 仍在熟悉平台

  * 正在积累品牌合作案例

  * 可能需要更清晰的推广说明

  * 合作态度通常认真且有热情

### **Advocate**

正在成长中的创作者。这类创作者已经完成了一些合作，对平台流程有基本理解。

**对卖家意味着什么？**

  * 有初步合作经验，展现出持续参与的意愿

  * 了解平台的基本运作方式，并持续学习和提升使用能力

适合扩展已有活动或培养潜力合作对象

**您可以预期：**

  * 对 Levanta 有一定操作经验

  * 正在提升内容与合作能力

  * 愿意拓展更多合作方向

### **Ambassador**

经验成熟、表现稳定的创作者。已经建立多次成功合作，具备较强的内容创作与执行能力。

**对卖家意味着什么？**

  * 熟悉平台规则，并展现出稳定投入和长期合作意愿

  * 已成功建立多个品牌合作案例

  * 清楚如何为自己的受众制作有效、有转化力的内容

  * 适合用于扩大推广规模、产品发布或持续性合作

**您可以预期：**

  * 内容产出与发布节奏相对稳定

  * 已建立成熟的合作流程与沟通方式

  * 受众互动率和影响力持续增长

  * 合作执行相对可靠、可控

### **Leader**

表现突出、成果稳定的创作者

**这对卖家意味着什么：**

  * 经验丰富，拥有扎实的合作记录

  * 深刻理解什么样的内容能够带来销售与互动

  * 通常拥有忠诚度高、信任度强的受众群体

  * 适合重点项目、复杂合作，或对专业度与稳定性要求较高的推广活动

**您可以预期：**

  * 专业、规范的合作方式

  * 较强的销售表现与转化能力

  * 在内容和活动策划上具备策略思维

  * 能提供有价值的反馈与优化建议

  * 基本无需过多指导即可顺利执行

## **如何运用等级来筛选创作者？**

**用于快速上线的活动：**
所有等级都有机会带来效果，但 Ambassador 和 Leader 通常经验更成熟，前期沟通和磨合时间会更短。

**用于长期合作：**
可以考虑从活跃度高的 Starter 或 Advocate 开始，一起成长，逐步建立稳定合作关系。

**用于重点或高风险发布：**
Leader 通常结果更稳定、可预期性更高，但由于其受众基础成熟，整体合作成本可能相对较高。

**用于真实测评需求：**
所有等级都可以产出真实评价内容。如需要更具深度的产品分析或更强的内容专业度，也可以考虑具备编辑能力的创作者或 Publisher 类型。

**建议做法（推荐）：**
结合不同等级的创作者进行搭配合作，有助于覆盖更广泛的受众群体和市场层级。

## **如何晋升等级？**

创作者的等级会根据以下表现逐步提升：

  * 成功完成多样化的品牌合作

  * 销售表现与受众互动情况

  * 在平台上的活跃度与持续输出能力

  * 对 Levanta 各项功能的熟练度提升

  * 在创作者社区中的参与度

这意味着，等级越高的创作者，通常已经展现出持续稳定的合作成果，并具备更成熟的平台使用经验与专业能力。

## **与不同等级创作者合作的建议**

### **Starter**

  * 提供清晰明确的合作说明和预期目标

  * 适当给予指导和最佳实践建议

  * 保持建立长期合作关系的开放态度

**Advocate**

  * 继续提供清晰的 brief，同时可以增加更多协作式沟通

  * 适合用于扩大已有推广活动

  * 认可并支持其不断提升的能力

### **Ambassador**

  * 充分利用其逐渐成熟的专业经验

  * 可以尝试新的推广形式或活动类型
借助其持续增长的势头和积极性

### **Leader**

  * 信任其专业判断，尽可能给予创作自由

  * 邀请其参与活动策略层面的讨论

  * 适合用于品牌重点或旗舰级项目

## **重点总结**

Creator Tiers 不只是一个等级标识，更代表创作者的经验、投入度和能力水平。您可以将等级作为筛选创作者的参考起点，帮助找到更符合推广目标的合作对象。只要匹配得当，每个等级的创作者都有机会带来出色的合作成果。

创作者的等级会随着其在平台上的成长自动更新，确保您随时看到的是其当前真实的经验水平。

# 如何高效运用按点击付费（CPC）广告活动

Last updated 6 days ago

## **按点击付费（CPC）最佳实践、产品演示与常见问题**

### **概览与核心优势**

按点击付费（Cost-Per-Click，简称 CPC）是一种强有力的营销策略，可在现有的按获客成本 CPA模式基础上，进一步提升品牌在 Amazon 上的曝光度并带来更优的整体表现。

通过 CPC 广告活动，卖家不仅可以拓展产品曝光渠道，还能与更多优质创作者建立新的合作关系，从而实现业务增长。

我们建议卖家在以下情况下启动 CPC 活动：

**1\. 解锁增量流量资源**

通过 CPC，您可以触达更多新的内容创作者，同时也能让现有合作伙伴采用新的推广渠道和营销策略，为品牌带来额外的增量流量。

**2\. 在竞争中脱颖而出**

CPC 为创作者提供了一种差异化的收益方式，让他们可以基于所带来的高质量点击流量获得回报，从而更愿意优先推广您的产品。

**3\. 提升自然搜索排名**

更广泛的曝光意味着更多流量。当您的商品页面获得更多点击和转化后，有助于提升 Amazon 平台上的自然排名，使产品更容易被潜在消费者发现。

**4\. 打造长期品牌价值（LTV）**

CPC 广告不仅有助于短期流量增长，还能持续提升品牌认知度和用户兴趣，从而带来更高的复购率和更强的品牌忠诚度。

**5\. 灵活的预算控制**

CPC 模式让您对广告支出拥有更高的掌控权。您可以根据实际效果灵活设置预算并调整出价，以最大化投资回报率（ROI）。

## **产品演示**

## **初始设置的注意事项**

  * 在决定启动 CPC 广告活动时，我们建议从新的产品品类开始，以提升品牌曝光度并激发市场兴趣。

  * CPC 单次点击价格（CPC Rate）理想情况下应高于平均 EPC，这样在大多数情况下可以为创作者解锁更多的增量流量资源。

    * EPC（每次点击收益）= 创作者获得的总佣金 ÷ 点击次数

  * 初期建议设置相对充足的预算，预算水平可参考或高于当前的月均推广支出，以覆盖不可避免的增量流量成本。 推荐预算范围：$5,000 – $10,000 美元

## **常见问题（FAQ）**

  1. **CPC 广告活动结束或预算用尽后，流量会如何变化？**

由于 Levanta 与 Amazon API 的通信机制，即使预算已用尽，CPC 广告活动仍可能在当日剩余时间内继续保持在线。因此，我们建议在设置预算时预留一定的“缓冲空间”。

当 CPC 广告活动因预算或时间到期而结束后，相关链接仍会继续通过 Levanta 进行追踪，并自动恢复至该 ASIN 原先设定的 CPA 佣金比例。

  2. **是否有预算提醒通知？**

有的呢，当广告活动的预算使用率达到 **50%、75% 和 100%** 的时候，您将会收到相应的通知提醒。

  3. **CPC 广告活动是按照哪个时区运行的？**

CPC 预算本身不受具体时区影响，但广告活动的开始和结束时间将基于产品所在的 **Amazon 站点区域时区** 。

  4. **我可以编辑已经创建的 CPC 广告活动吗？**

目前暂不支持编辑已创建的广告活动，因此在上线前请务必确认所有设置内容准确无误。广告活动的编辑功能将在后续版本中推出，敬请期待。

# 付费推广合作入门指南（卖家版）

Last updated 1 month ago

**Paid Placements** （付费推广合作） 允许品牌与创作者直接合作，开展赞助内容推广，拥有清晰的报价、明确的交付内容，以及平台内置的付款保障机制。

Levanta 将整个流程标准化管理 —— 从提案、内容发布到付款，全部在平台内完成，无需通过私信或线下合同沟通，让合作更加安心、高效、可追踪。

本文将为您说明：

  * 什么是付费推广合作（Paid Placements）

  * 什么是报价卡（Rate Card）

  * 如何发送合作提案

  * 各种状态的含义

## **什么是付费推广合作？**

**付费推广** 合作是一种品牌向创作者支付固定费用，以换取指定推广内容的合作形式。这可以包括社交媒体帖子、短视频、电子版推荐、博客文章或双方事先约定的其他推广方式。

推广付费合作通常会明确约定：

  * 内容类型（例如 Instagram Reel、TikTok 短视频、Newsletter 推荐）

  * 价格

  * 是否包含内容使用权

  * 创作时间、审核时间及发布时间

Levanta 提供端到端管理，确保双方条款清晰、权益受到保障。

## **付款手续费**

根据所选择的支付方式，费用会有所差异：

• 使用信用卡支付的合同：**10%** 手续费
• 通过 ACH（银行转账）充值钱包后支付的合同：**7.5%** 手续费

在设置和充值合同时，请将相关费用一并考虑在内。

## **什么是报价卡？**

报价卡是创作者的“付费推广报价单”，包括：

  * 可提供的推广类型

  * 每种推广形式的报价

  * 单独列出的内容使用权价格（如适用）

作为卖家，您可以通过查看报价卡快速了解：

  * 创作者提供哪些内容形式

  * 各项推广的基础报价

  * 是否提供内容使用权及对应价格

创作者仅会列出自己实际提供的推广形式，因此您在报价卡中看到的内容均可以发起合作提案。

## **卖家如何使用付费推广合作**

     📌 如要发送付费推广合作提案，您的账户必须已绑定有效的信用卡或借记卡。

  1. **创建新提案并浏览创作者报价卡**

当创作者发布了报价卡后，您可以查看：

  * 标准推广形式（按平台分类：Instagram、TikTok、YouTube 等）

  * 自定义推广形式（如博客、播客、Newsletter、测评等）

  * 内容使用权价格

报价卡显示的是创作者的基础报价，可以协商，并非固定价格。

您还可以使用筛选功能（如创作者分组、推广方式、粉丝数量等）更高效地找到符合您推广目标的创作者。

  2. **发送推广付费合作提案**

当您准备好与创作者合作时，可直接在 Levanta 平台发送提案。提案包含以下内容：

  * **选择推广形式（Select Placements）**

选择希望创作者推广的类型。系统会显示该推广形式的基础报价供参考。

您看到的推广形式基于该创作者提供或擅长的推广方式。只有他们选择包含在报价卡中的合作类型才会可见并可供选择。

  * **自定义报价（Customized Selected Placements）**

虽然创作者通过其报价卡设定了价格，但卖家仍然可以协商定价和条款，以使其与活动目标保持一致。此步骤允许您调整定价并提出更符合您预算和目标的报价。

  * **选择推广的产品（Select Products to Promote）**

选择您希望创作者推广的具体产品。这可以让您将所选择的推广形式与本次活动中希望重点推广的产品进行匹配与对应。

  * **内容指导（Content Guidelines）**

请通过明确列出本次合作内容的「可做事项」与「不可做事项」为创作者提供清晰指引，从而确保最终内容符合您的品牌调性、核心信息传达及整体预期。

  * **附加条款（Additional Terms）**

您可以为本次合作设置额外条款，例如明确截止日期规定创作者可进行修改的天数或修改期限。此外，您还可以添加以下授权类型：

  * **Repost Rights（转发权限）：** 申请获得在内容原发布平台进行转发或赞助推广的权限。

  * **Social Media Boosting（广告投放权限）：** 申请在内容原发布平台上直接进行广告推广或付费加热。

  * **Content Rights（内容使用权）：** 向创作者申请额外的内容使用授权，并协商费用，以便您将其内容用于其他推广或营销用途（例如广告投放、官网、邮件营销等）。

  * **标题（可选）**

为您的提案添加一个标题，有助于与其他合同区分开，并便于管理您的推广活动。

  * **提案摘要（Proposal Summary）**

显示本次提案的总费用，并允许您选择首选的付款方式。

  3. **协商并达成协议**

创作者可以：

  * 接受提案

  * 对价格、时间安排或使用权条款提出修改建议

  * 拒绝提案

所有协商都在 Levanta 内完成。一旦双方达成一致，合作将自动进入执行阶段。

  4. **合同与内容审核**

当提案被接受后，您将看到专属合同管理页面：

  * **Contract Details（合同详情）：** 查看合同概览，包括双方已确认的合作条款及付款信息。

  * **History（历史记录）：** 查看合同内的完整操作记录，方便追踪合作进展与所有相关动态。

  * **Content（内容）：** 审核创作者提交的内容，并进行批准或提出修改反馈。

## **余额充值与样品（Credits & Sampling）**

付费推广中现已新增两项功能，帮助您在与达人合作时拥有更灵活的操作方式。

**余额充值**

现在您可以通过 ACH（银行转账）为付费推广钱包预先充值，无需使用信用卡或借记卡。使用余额进行支付可享受更低的服务费：7.5%，相比标准的 10% 可节省 2.5%。

请前往Payments页面，通过 ACH 为钱包充值。充值完成后，在提交任何付费推广合作提案时，选择余额作为支付方式即可。

### **样品**

您可以在付费推广合作提案中直接添加产品样品，无需再单独对接。只需在提案中加入样品，后续流程将由 Levanta 统一处理，让您可以更高效地在达人开始创作前将产品寄出。

这两项功能旨在减少操作流程中的沟通成本，让整个达人合作流程都可以在平台内完成。

## **状态说明（Placement Status）**

在仪表板中您会看到以下状态：

  * **New（新提案）：** 提案已发送，创作者尚未回复。

  * **Accepted（已接受）：** 已确认并同意合作条款。

  * **Submitted（已提交）：** 创作者已提交内容或发布链接，等待您审核。

  * **Approved（已批准）：** 内容已通过审核，并已通知创作者可正式发布。

  * **Placed（已发布）：** 内容已正式上线。

  * **Complete（已完成）：** 内容全部发布，付款即将释放。

## **合同类型**

合同分为三个分类：

  * **Active Contracts（进行中）：** 当前正在执行或进行中的合作提案。

  * **Paid Contracts（已付款）：** 已全部执行完成的合作，包括内容已创作、发布、推广，且款项已释放给创作者。

  * **Archived Contracts（已归档）：** 已拒绝、取消或过期的合作。

## **付款流程说明**

Levanta 采用结构化付款流程，保障品牌与创作者双方权益。流程如下：

  1. **双方达成协议：** 当双方接受提案后，付款条款即被锁定确认。

  2. **扣款：** 系统将从您的付款方式中扣款，资金将安全存放于托管账户

  3. **托管期间：** 在创作者制作并发布约定内容期间，资金由 Levanta 平台安全保管。

  4. **内容发布：** 内容完成审核并正式发布后，交易进入上线观察期。

  5. **释放付款：** 在规定的上线观察期结束后，款项将释放给创作者。

这保障了创作者按时收款与确保品牌获得合格的交付内容，为双方提供安全又透明的合作保障。

## **卖家使用建议**

  * 在发送提案前，仔细查看创作者的报价卡，确保双方预期一致。

  * 在提案中清楚说明内容使用权及时间安排，避免因条款不明确而产生延误。

  * 合理使用 Counter（反提议）功能进行协商。报价卡价格为参考基础价，可协商。

  * 如果您计划将内容用于广告投放、邮件营销或官网等二次推广，请提前规划并购买相应的内容使用权。

## Deal 类型说明

创建 Deal 时，您需要从下拉菜单中选择相应的 **Deal 类型** 。不同类型代表消费者在亚马逊上获得优惠的不同方式：

优惠价格会直接显示在商品详情页，消费者无需领取优惠券或输入促销码即可享受折扣。此类型包括：秒杀优惠、Prime 会员日优惠、限时优惠和其他直接降价促销。

**2\. Clippable Coupon（可领取优惠券）**
消费者需要先在商品详情页点击优惠券按钮领取优惠。领取后，符合条件的商品将在结算时应用相应折扣。

## 调整佣金（Adjust Commissions）

## 什么是调整佣金？

亚马逊回传的销售金额，不一定会反映消费者实际支付的折后价格。对于部分促销类型，即使消费者使用了优惠，亚马逊仍可能向 Levanta 回传商品原价。

若未启用佣金调整，创作者佣金可能会按照亚马逊回传的原价计算。启用 **Adjust Commissions** 后，Levanta 会根据您填写的商品原价和折扣信息，**自动安排活动期间的佣金比例调整** ，使最终创作者佣金金额与折后价格相符。

## 什么时候需要开启调整佣金？

对于以下促销类型，建议启用佣金调整：

  * Lightning Deals（秒杀活动）

  * Coupons（优惠券）

  * Promo Codes（促销码）

这些促销的折后价格可能不会反映在亚马逊归因报告中，因此需要通过调整佣金比例，避免创作者佣金按照商品原价计算。

以下促销通常会由亚马逊回传正确的折后价格，因此无需开启佣金调整：

  * Discounted Deals（折扣活动）

  * Prime Day Deals（Prime Day 活动）

  * Limited-Time Deals（限时促销）

这些活动的佣金通常会直接按照消费者实际支付的价格计算。

    目前 Subscribe & Save 不支持创建 Deals，也不支持佣金调整。

**💡提示：** 即使同样属于 **Deal（直接降价促销）** ，不同的亚马逊促销类型在销售金额回传方式上可能有所不同，因此是否需要开启佣金调整，应以具体的促销类型为准。

## 具体步骤：

在上传 Deals `.csv` 文件或者手动创建Deals时：

  * 将 **Adjust Public Commissions** 设置为 **Yes** （公开佣金）

  * 或将 **Adjust Private Commissions** 设置为 **Yes** （私密佣金）

这样系统会根据 Deal 的折扣信息，自动安排活动期间适用的佣金比例调整。

## 开启佣金调整后会发生什么？

启用后，Levanta 会在 Deal 活动期间自动安排新的佣金比例。虽然亚马逊仍可能回传商品原价，但系统会降低活动期间适用的佣金比例，使最终创作者佣金金额与折后价格对应。

### 示例

  * 商品原价：$100

  * 折后价格：$50

  * 原佣金比例：10%

如果未开启佣金调整：

$100 × 10% = $10 创作者佣金

如果开启佣金调整，Levanta 会将活动期间的佣金比例调整为 5%：

$100 × 5% = $5 创作者佣金

这与按照折后价格和原佣金比例计算的结果一致：

$50 × 10% = $5 创作者佣金

因此，您可能会看到活动期间的佣金比例从 10% 变为 5%。这并不是额外降低创作者应得佣金，而是为了在亚马逊回传原价的情况下，使最终佣金金额与折后价格保持一致。

## Deal 结束后会发生什么？

系统会按照已安排的佣金设置恢复后续适用的佣金比例。您也可以在产品页面查看已计划的[ _佣金调整_](https://app.levanta.io/seller/products/scheduled-commissions/public)

##  ‼重要说明

佣金调整只会改变活动期间的创作者佣金比例和最终佣金金额。

它不会修改亚马逊归因回传的销售价格，因此 Levanta 控制面板中显示的 Sales 或 GMV 仍可能是商品原价。

**平台的 variable rate fee 也会继续根据亚马逊回传的 GMV 计算。**

# 了解亚马逊品牌引流奖励计划

Last updated 9 days ago

## **概览**

亚马逊的品牌引流奖励（[ _Amazon’s Brand Referral Bonus_](https://sellercentral.amazon.com/help/hub/reference/external/GL9HPJ34VBFP76HX?initialSessionID=137-7590772-6016720&ld=NSGoogle), 简称 BRB）计划，允许卖家针对来自站外的合格流量获得奖励回馈。

当您通过归因标签（例如由 Levanta 生成的标签）将流量引导至亚马逊，并且该流量成功产生销售时，亚马逊可能会向您的账户发放品牌引流奖励。

这些奖励将推荐费返还的形式计入您的账户，用于抵扣未来的亚马逊推荐费用，帮助您更高效地利用营销预算。

    ⚠ 请注意：必须严格遵守该计划的所有规则与要求。若未符合规范，可能会导致奖励被取消，甚至被移出该计划。

## **品牌引流奖励（BRB）的运作方式**

品牌引流奖励按月计算，并会以亚马逊推荐费返还的形式发放。您可以在亚马逊卖家后台的 Payment Repository Report（付款存储库报告） 中查看相关记录。

    📌 请注意：奖励的处理时间最长可能需要 2 个月，以便亚马逊计算可能发生的退货或订单取消情况。

## **如何在 Levanta 查看品牌引流奖励（BRB）报告**

您可以通过 Levanta 报表面板，轻松查看预估的品牌引流奖励金额，操作步骤如下：

  1. 前往 Reports（报表）标签页

  2. 点击 More Reports -> BRB Report，打开品牌引流奖励报表

  3. 使用以下筛选条件自定义查看内容：

  * Brand（品牌）

  * Product（产品）

  * Ad payout model（广告结算模式）

您也可以选择想查看的日期范围，以观察不同时间段的奖励预估变化。

    📌 注意：这些收入是基于站外营销链接所追踪销售的预估值。实际的奖励发放与结算，仍以亚马逊卖家中心为准。

## **怎么算作合格的流量和订单？**

### **合格流量**

指的是来自亚马逊站外的平台流量（如社交媒体、博客、网站等），并且该流量是通过由 Levanta 生成的亚马逊归因标签，引导至您的产品页面或品牌店铺。只要用户是通过这些带有归因标签的链接点击进入，就会被视为合格流量。

### **合格购买订单**

指的是客户在点击合格流量链接后的14 天内完成的购买行为。只要购买发生在这 14 天内，就会计入品牌引流奖励的计算。

    📌 小提醒：请务必使用正确的 Levanta 生成链接，以确保你的流量和订单能够被亚马逊正确追踪与统计。

## **遵守亚马逊品牌引流奖励与亚马逊联盟计划规范**

为了在获取品牌引流奖励的同时保持合规，请特别留意以下重点规则：

  1. **同时性收入 - 每个标签仅限一个计划**

对于在[ _Amazon Attribution_](https://advertising.amazon.com/solutions/products/amazon-attribution)中创建的单个标签，您只能获得品牌引流奖励或亚马逊联盟佣金中的其中一种。

若亚马逊发现您尝试对同一标签获取两种收益：

  * 相关奖励可能会被拒绝

  * 您可能会被移出其中一个或两个计划

  * 在严重或多次违规的情况下，甚至可能导致卖家账户或联盟账户被终止

  2. **流量来源要求**

  * 只有来自已批准、符合品牌安全标准的流量来源，才有资格获得奖励

  * 若流量来源违反亚马逊的相关政策，亚马逊有权拒绝该流量。

可参考 [_亚马逊联盟计划_](https://affiliate-program.amazon.com/help/operating/policies) 参与要求中第 1(a)–1(f) 条的相关说明。

  3. **保持合规的关键做法**

为了顺利获得并保留品牌引流奖励，请确保：

  * 每个归因标签只使用一个计划

  * 您的站外流量来源符合亚马逊的所有规范

  * 定期查看卖家后台中的品牌引流奖励相关条款

# 管理产品佣金

Last updated 9 days ago

## **调整产品佣金**

Levanta 允许卖家通过多种灵活方式管理佣金，例如：

  * 调整 公开佣金比例（Public Rates）

  * 为特定 创作者设置私有佣金（Private Commissions）

  * 提前安排佣金调整时间

## **1\. 更新单个产品的佣金**

如果您想调整**单个产品的佣金比例** ：

  * 前往 Products 页面

  * 点击该产品进入 产品详情页面

  * 点击绿色的佣金百分比来编辑佣金比例

## **2\. 批量更新多个产品的佣金**

如果您需要为多个产品设置**公开佣金（Public Commissions）** ：

  * 在左侧导航进入 **Products**

  * 选择您想要更新的产品（提示：您可以在右下角调整每页最多显示 **50 个产品** ）

  * 点击左上角 **Actions**

选择 **Set Public Commissions** 进行批量设置

## **3\. 为特定创作者设置私有佣金**

您也可以与某个**创作者** 单独协商佣金比例。

这种自定义的联盟佣金被称为 **Private Commissions（私有佣金）** 。

设置自定义佣金的方法：

  * 前往 Creators → Private Commissions，然后点击 New Private Product Commission（新建私有产品佣金）。

  * 选择对应的创作者或创作者分组、产品，并设置创作者佣金比例。

  * 如果您希望该佣金在指定日期生效，请勾选 Schedule For a Future Date（安排在未来日期生效），然后设置您希望的生效日期。

  * 点击 Save Private Commission（保存私有佣金） 完成设置。

⚠ **提示** ： 私有佣金将覆盖公开佣金，并适用于后续产生的转化。私有产品佣金的优先级始终高于 品牌级私有佣金。

⚠ 提示： 此更改不会影响之前的佣金，仅适用于后续产生的转化。

## **品牌级私有佣金（Private Brand-Wide Commissions）**

品牌级私有佣金允许您针对特定创作者或创作者分组，为整个品牌的产品目录统一设置一个佣金比例，无需逐一调整每个产品的佣金。

### **设置品牌级私有佣金**

  1. 在左侧导航栏前往 Creators → Private Commissions。

  2. 点击 Private Brand-Wide Commissions（品牌级私有佣金） 标签页。

  3. 点击 + New Private Brand-Wide Commission（新建品牌级私有佣金）。

  4. 选择对应的 Creator or Creator Group（创作者或创作者分组）。

  5. 选择您希望应用该佣金比例的品牌。

  6. 输入创作者佣金比例。Levanta 的 2.5% 平台费用及总费用将自动计算。

  7. 点击保存私有佣金完成设置。

### **适用场景：**

  * Card-Linked Offer（CLO，银行卡关联优惠）类创作者：CLO 项目通常需要针对整个品牌产品目录设置统一的佣金比例。当消费者在银行 App 中激活返现或积分奖励后，该优惠会适用于该商家的整个产品目录，因此品牌级私有佣金非常适合此类创作者。

  * 希望快速为创作者设置全品牌统一佣金的品牌：无需逐一调整每个 SKU，即可为指定创作者或创作者分组设置具有竞争力的统一佣金比例。

## **4\. 安排佣金调整时间**

通过提前安排佣金调整时间，您可以在未来某个时间自动更新创作者佣金。
此功能可通过设置时间窗口，为未来的佣金调整安排临时的公开佣金或私有佣金比例。

为单个产品安排佣金调整：

  * 打开该产品的 Product Details Page

  * 点击当前的 佣金比例 打开编辑窗口

  * 勾选 “Schedule For a Future Date?”

  * 设置您希望的 佣金比例 以及 生效日期

  * 所有定时更新都会按照 美国东部标准时间（Eastern Standard Time, EST） 处理

## **为多个产品安排佣金调整：**

  * 前往 **Products 页面**

  * 选择您想更新的产品

  * 点击 **Actions** ，然后选择 **Set Public Commission** 或 **Set Private Commission**

  * 输入未来的佣金比例并设置生效日期

## **查看已安排的佣金调整：**

您可以通过以下方式查看所有已安排的佣金变更：

  * 在 **Your Products** 页面最底部

  * 点击 **“View Scheduled Commission Changes”** 查看详情

# 私有佣金 （产品及品牌级）、忠诚奖励计划（LBP）与奖励支付完整指南

Last updated 9 days ago

## **概述**

Levanta 提供三种方式来奖励和激励表现优秀的创作者：私有佣金、忠诚奖励计划以及奖金支付。虽然这三种激励方式都旨在提升创作者的积极性并加强合作关系，但它们各自适用于不同场景，并在平台中的不同模块进行管理。了解每种方式的特点及适用时机，有助于您打造更完善、更具竞争力的创作者合作计划。

## **1\. 私有佣金**

私有佣金允许您为特定创作者或创作者分组设置专属佣金比例，而无需使用公开联盟计划中的默认佣金比例。

**操作方式：**
选择指定创作者及产品后，即可设置自定义佣金比例。例如，您可以将某位表现优异的创作者，从公开佣金的 10% 提升至专属佣金的 15%，作为对其推广表现的奖励。

**适用场景**

  * 奖励 Levanta 联盟计划中的高绩效合作伙伴

  * 为新品上市提供额外推广激励

  * 与重点合作伙伴争取独家或优先曝光机会

**主要优势**

可针对创作者及产品进行精细化管理，让您能够将更高的佣金激励精准应用于最重要的合作伙伴和产品，从而最大化推广效果与投资回报

## **2\. 品牌级私有佣金**

品牌级私有佣金允许您为特定创作者或创作者分组，在整个品牌商品目录范围内设置统一佣金比例，而无需逐个产品进行配置。

**设置步骤：**

  1. 在左侧导航菜单中，前往 **Creators → Private Commissions**

  2. 点击 **Private Brand-Wide Commissions** 标签页

  3. 点击 **\+ New Private Brand-Wide Commission**

  4. 在弹窗中选择创作者或创作者分组

  5. 选择要应用佣金比例的品牌

  6. 输入创作者佣金比例（CC）。Levanta 的 2.5% 平台服务费及总费用将自动计算。

  7. 点击 **Save Private Commission**

**适用场景**

  * Card-Linked Offer（CLO）创作者：CLO 项目通常要求整个商品目录采用统一佣金比例。当消费者在银行 App 中激活返现或积分返还活动时，该优惠会适用于品牌的全部商品，因此品牌级佣金对于此类创作者尤为重要。

  * 希望快速为创作者设置覆盖全品牌商品目录的统一佣金比例，而无需逐个 SKU 单独配置的品牌。

⚠**重要说明**

产品级私有佣金的优先级高于品牌级私有佣金。如果您已经为某位创作者的特定产品设置了专属佣金比例，则系统将优先采用该产品级佣金，而不会使用品牌级佣金。

这使您能够针对特定 SKU 制定差异化佣金策略，同时保持品牌整体佣金体系的统一性。

## **3\. 忠诚奖励计划**

忠诚奖励计划（LBP）专为使用 Levanta 亚马逊 CC 集成的品牌设计。由于亚马逊会在 CC 活动中设定固定佣金比例（例如美妆类目的标准佣金为 10%），品牌无法直接调整基础佣金比例。

LBP 通过在亚马逊固定佣金的基础上叠加额外奖励，让品牌能够为创作者提供更具吸引力的激励方案。

**操作方式**

您可以设置基于业绩目标的奖励机制。当创作者通过 CC 活动达到指定销售额门槛时，即可获得额外奖金。

例如：创作者每产生 10 美元销售额，您可额外奖励其 1 美元奖金。

**适用场景**

  * 扩大与高绩效 CC 创作者的合作规模

  * 提供亚马逊 CC 平台原生功能不支持的个性化奖励

  * 提升品牌竞争力，吸引并留住优质 CC 创作者

💡**小贴士：使用创作者分组进行批量管理**

对于产品级私有佣金、品牌级私有佣金以及忠诚奖励计划，您都可以直接将激励方案应用至创作者分组，而无需逐位创作者单独设置。

这样不仅能确保核心创作者持续获得一致的激励政策，还能大幅减少逐个管理合作关系所带来的运营成本。

## **4\. 奖金支付**

奖金支付允许您在常规佣金收入之外，向创作者发放一次性的额外奖励。这非常适合用于奖励表现特别优秀的创作者、庆祝重要里程碑，或补偿不属于常规佣金体系范围内的合作内容。

**操作方式**

  1. 前往 **Payments → Bonus Payments**

  2. 点击 **Send Bonus Payment to a Creator**

  3. 在弹窗中填写以下信息：

     * **Creator** ：选择您要奖励的创作者

     * **Brand** ：选择奖金关联的品牌

     * **Amount** ：输入您希望发放的奖金金额

  4. 点击 **Checkout** 完成付款

**查看奖金支付记录**

所有已发放的奖金都会记录在 **Payments → Bonus Payments** 页面中。

表格将显示以下信息：

  * 创作者（Creator）

  * 品牌（Brand）

  * 金额（Amount）

  * 状态（Status）

  * 日期（Date）

  * 发票查看链接（View Invoice）

方便您随时追踪和管理奖金发放记录。

⚠ **注意**

奖金支付属于额外费用，将在常规佣金支付之外单独收取。所有奖金支付均需支付 **4.15% 转账手续费** 。

# 产品寄样管理指南

Last updated 2 days ago

## **功能概览**

通过 Levanta，您可以在后台统一完成：

  * 审核创作者的样品申请

  * 发货（自动履约）

  * 跟踪寄样状态

所有操作均可在一个界面内完成，无需额外沟通或手动处理。

📌 **注意：** 产品寄样功能仅对 **Gold 和 Enterprise** 卖家开放。如需升级，请联系：[ _cs@levanta.io_](mailto:卖家开放。如需升级，请联系：cs@levanta.io)

## **添加 Amazon Selling Partner 连接**

在使用寄样功能前，您必须先完成 Amazon 店铺连接。

操作路径：

  * Settings → Connections → Add Amazon Connection → Add Amazon Selling Partner Connection

在下拉菜单中，请选择最后一个选项：**”Add Amazon Selling Partner Connection”**

⚠ 注意：其他选项是用于 Amazon Ads，不会连接您的店铺后台。连接成功后，即可解锁 Levanta 的 Samples（寄样）功能。

### **启用 Shopify 产品寄样功能**

您也可以为通过 **Shopify** 连接的产品启用寄样功能。

在开始之前，请先确认您的 **Shopify** 店铺已成功连接至 Levanta。

操作步骤如下：

  1. 前往 **Settings → Connections → Shopify → Add Shopify Connection** ，并按照页面提示完成店铺连接。

  2. 店铺连接完成且品牌已成功激活后，前往 **Products（产品）** 页面。

  3. 勾选您希望启用寄样功能的产品。

  4. 点击 **Actions** ，选择 **Enable Samples** 即可启用寄样功能。

## **Shopify 寄样的履约与费用说明**

当卖家批准**通过 Shopify 同步的产品** 寄样申请后，Levanta 会自动在卖家的 Shopify 店铺中创建一笔 **金额为 $0.00 的订单** ，用于处理该寄样请求。

### **这意味着：**

  * **订单金额** ：Levanta 会自动在卖家的 Shopify 店铺中创建一笔 **$0.00** 的寄样订单。

  * **平台费用：** 目前，Levanta 不会针对通过 Shopify 履约的寄样收取单件自动化处理费用。由于订单金额为 $0.00，按订单金额计算的 3.5% Shopify Attribution 平台费用也将为 $0.00。

  * **履约费用：** 商品仍会按照卖家现有的 Shopify 履约流程进行处理，因此运费以及 3PL（第三方物流）或仓库产生的履约费用，仍由卖家自行承担。

### **总结**

如果您使用 Shopify 履约寄样订单，Levanta 不会收取任何按件计算的费用。系统仅会自动在您的 Shopify 后台创建一笔标记为 "Created by the Levanta app"（由 Levanta 应用创建） 的 $0.00 订单，方便您的团队按照日常流程完成发货。

## **寄样管理面板**

在 Products → Samples 中，您可以查看和管理所有寄样请求：

**各状态说明：**

  * Incoming（待处理）：创作者发起的样品申请，可在此审核（通过/拒绝）

  * Sent（已发送）：您主动发起寄样，等待创作者确认

  * Accepted（已接受）：已批准的寄样（包括创作者已确认的样品）

  * Rejected（已拒绝）：被您或创作者拒绝的请求

  * Archived Product Samples（已归档）：超过**3个月** 未处理的请求会自动归档（无论当前状态）

## **寄样流程**

  1. 创作者对您的产品发起寄样申请

  2. 您可以在 **Samples → Incoming** 中审核请求（通过 / 拒绝）

  3. 当您点击“接受”后，系统会提示该创作者是否已有带货表现（是否有销售记录），您可以自行判断是否寄样

  4. 批准后，Levanta 将通过 Amazon 自动完成发货与订单跟踪，无需人工发货

## **为什么使用寄样功能？**

  * **提升履约效率** ：一键发货，无需邮件沟通

  * **快速建立合作** ：降低与新创作者合作门槛

  * **产出真实内容** ：创作者基于真实体验进行推广

  * **全流程可追踪** ：所有寄样记录统一管理

## **寄样履约与费用说明**

通过 Levanta 发送的样品，将通过 Amazon MCF（Multi-Channel Fulfillment) 发货。

说明如下：

  * 按每个寄样商品计费

  * 适用标准 FBA MCF 费用

  * 发货由 Amazon 完成（使用您的 FBA 库存）

## **寄样数据与报表说明**

由于寄样通过 MCF 发货：

  * ❌ 不会出现在 Amazon Business Reports（普通销售报表）

  * ✅ 会体现在 Amazon 的 **MCF 报表** 中

建议做法：

  * 在内部记录寄样数据（如表格）

  * 使用 Levanta 查看寄样与创作者匹配情况

  * 结合 Amazon MCF 报表进行核对

👉 Levanta + 内部记录 = 更完整的数据追踪方式

## **创作者申请限制**

为了保证寄样质量，系统会根据创作者等级限制申请数量。这有助于：

  * 提高申请质量（高意向创作者）

  * 避免无效寄样

  * 提升资源利用效率

**操作步骤：**

⚠ 注意：必须先完成 Stripe 设置，才能更新地址

  * 样品申请必须由创作者接受，才会进入发货流程

  * 超过 **14天未处理** 的请求将自动归档

# Levanta 的税务运作方式：W9、1099 与 Stripe

## **合同关系说明**

Levanta 的主要作用是连接卖家与内容创作者，帮助双方建立联盟营销合作关系。需要特别说明的是：联盟合作关系是直接存在于卖家与创作者之间的，Levanta 并不是这些合同的签约方。

为了简化付款流程与税务文件的管理，Levanta 与 Stripe 合作，由 Stripe 代表卖家负责税务信息的收集以及 1099-K 表格 的发放。

## **W9 信息收集 & 1099-K 报告（通过 Stripe）**

  * **创作者必须先向 Stripe 提交税务信息（W9 表格）** ，才能通过 Levanta 接收佣金付款。

  * 在每个自然年度结束时，**Stripe 会向符合条件的创作者发放 1099-K 表格，** 前提是该创作者当年的推广收入达到或超过美国税务规定的金额门槛。

  * 在大多数情况下，**卖家无需单独向创作者发放 1099 表格。** 不过，具体是否需要另行申报，仍可能因卖家的业务结构或税务安排而有所不同。

    ⚠ 我们建议您就自身情况咨询专业税务顾问，以获取最合适的税务建议。

## **可选方案：自行收集 W9 并独立开具 1099**

如果您希望在 Levanta 平台之外自行管理税务文件，也可以选择以下方式：

  * 您可以通过应用内聊天或电子邮件，**直接向创作者索取 W9 表格** 。

  * 如有需要，您也可以根据自身的会计或财务流程，**自行向创作者开具 1099 表格** 。

## 27. Levanta 支付说明：账单、付款方式与佣金费用

# Levanta 支付说明：账单、付款方式与佣金费用

Last updated 4 months ago

本指南将介绍 Levanta 的账单生成、付款流程以及 Creator 佣金支付机制，包括如何设置付款方式，以及如何避免不必要的交易手续费。

## **每月账单说明**

Levanta 会每月生成账单，帮助您高效管理 Creator 佣金和平台服务费用。

  * 佣金发票通常在每月 1 日至 3 日之间生成。SaaS 发票则根据您签署合同的生效日期或升级日期生成。

  * 每个品牌会分别生成一张佣金发票。SaaS 费用将合并为一张总账单。

  * 发票中会包含上个月的所有对账调整金额。

**示例：** 如果某位 Creator 在 2 月 12 日促成了一笔销售，该笔佣金的发票将在 3 月 1 日至 3 日之间生成。

  * Creator 的佣金付款将在发票生成日期后 30 天处理，前提是品牌/卖家已完成付款。

  * 如果开启了 Auto-Billing（自动扣款），您的付款方式将在发票生成当天自动扣款。

  * 如果未开启 Auto-Billing，发票将按照 Net-30 条款执行，即需在发票日期后 30 天内完成付款。

## **为自动扣款添加付款方式**

若您希望开启自动扣款并确保每月发票自动支付，请按以下步骤操作。

  1. 前往 Levanta 后台的**Payments** 页面，然后点击**“Set Up Payments”**

  2. 在继续之前，系统会弹出确认窗口，提示 Levanta 的信用卡手续费政策。请点击**“I Understand”** 继续。

  3. 系统将跳转至 Stripe Billing Settings 页面。

  4. 点击 **“+ Add payment method”。**

  5. 选择您偏好的付款方式，包括：

  * 信用卡或借记卡（支持 Link、Google Pay、Apple Pay）

  * ACH Direct Debit（美国银行账户）

## **付款方式重要说明**

  * 如果您选择使用**信用卡** 或移动支付方式，Stripe 将对 Creator 佣金支付**收取交易手续费** 。

  * 这些手续费**不适用** 于 Levanta 的 SaaS 或平台服务费用。

  * 若希望**避免交易手续费** ，建议尽可能使用 **ACH Direct Debit** 或**手动银行转账** 方式。

[ _Learn more about Creator Commission Transaction Fees_](https://levanta.io/pricing)

## **通过 ACH Direct Debit（美国银行账户）付款**

  * ACH Direct Debit 可连接您的美国银行账户，用于自动或手动付款，且**无交易手续费。**

  * 即使未开启 Auto-Billing，也可以使用 ACH Direct Debit。

## **若要设置 ACH**

  * 请前往 **Payments → Stripe Billing Settings**

  * 在 Stripe 页面中点击 “+ Add payment method”

  * 选择 US bank account

📌如果您在设置过程中遇到错误（例如银行或 Stripe 暂时不可用），请发送邮件至 [_operations@levanta.io_](mailto:operations@levanta.io) 并提供您的 ACH 信息。系统将要求您确认一个微额验证代码，该代码格式为 “SM-XXXX”。

## **关闭自动扣款时如何付款**

❗ 请注意，Standard Plan 用户无法关闭 Auto-Billing。

如果关闭了 Auto-Billing，发票将通过电子邮件发送给您，通常采用 Net-30 条款，即需在发票日期后 30 天内完成付款。

您也可以随时在 Levanta 后台的 **Payments** 页面查看发票。

## **通过银行转账付款**

如果未开启 Auto-Billing，您可以通过手动银行转账完成付款。

  * 发票上将提供所有必要的银行信息，包括 Routing Number、Account Number 或 SWIFT Code。

  * 您可以使用这些信息通过银行进行手动付款。

❗请注意，银行转账通常需要最多 **5 个工作日** 处理。我们建议尽早发起转账，以确保款项在发票到期日前到账。

## **Creator 佣金交易手续费**

  * 根据我们的服务条款，卖家需承担 Stripe 在处理创作者佣金时产生的支付手续费。

    * 美国信用卡手续费为 2.9%。

    * 涉及货币转换的国际信用卡手续费最高可达 5.4%。

  * 这些手续费不适用于 Levanta 的 SaaS 或平台费用。

  * 如希望避免手续费，可选择使用 ACH Direct Debit 或手动银行转账。

## **添加账单接收邮箱**

如果您希望发票发送至除 Levanta 账户绑定邮箱之外的其他联系人

  1. 请前往 Payments 页面，

  2. 点击 “Stripe Billing Settings”

  3. 系统将打开 Stripe 的账单设置页面

  4. 在该页面中，您可以更新账单邮箱地址、添加 CC 抄送收件人以接收发票副本，或在 “Description” 中更新您的账单名称或公司名称。

这有助于将发票直接发送至财务团队或其他相关负责人。

## **退货与撤销转化**

如果您已经支付了一张包含佣金的发票，但对应的转化在发票日期后的30天内被撤销（例如发生退货或订单取消），Levanta 将会：

  * 在下一张发票中进行对账调整（reconciliation adjustment）

  * 该调整将用于抵扣因退货或取消订单而多支付的佣金

这可以确保您不会为未最终完成销售的转化支付费用。

## **延迟归因**

亚马逊归因在报告转化数据时通常存在**24–48 小时的延迟。**

为确保月度发票能够反映所有有效转化，Levanta 会在**每个月结束后等待 48 小时** ，再生成佣金发票。这样可以统计到发生在月底最后几天的销售。

然而，在极少数情况下，Amazon 可能会在超过 48 小时之后才将某笔销售归因给 Creator。当出现这种情况时：

  * 该笔转化可能不会显示在当月发票中。

  * Levanta 会在下一张发票中加入对账调整，以补计遗漏的佣金金额，从而纠正少付情况。

这些调整通常金额较小，但有助于确保所有符合条件的佣金最终都被准确记录。

## **了解 Halo Effect**

除了直接转化的数据之外，Levanta 也可以帮助您看到联盟营销带来的整体效果，也就是所谓的 Halo Effect。简单来说，即使用户没有通过带有归因的链接立即下单，达人带来的流量依然会为品牌带来间接价值，并在后续产生转化。

Halo 带来的效果通常需要一段时间的积累才会逐步体现，也会让整体投放更有价值。它不仅能反映标准报表之外的 ROI 表现，也有助于降低对佣金调整的顾虑，同时提升用户复购以及对品牌的认可度。

## **品牌认知（Brand Awareness）**

品牌认知无法仅通过归因数据直接衡量，但可以从亚马逊上的一些用户行为中体现出来。当归因使用得当时，即使当下没有立即产生订单，也可以看出站外流量是如何为品牌带来需求，并在后续通过自然流量完成转化。

**在报表中，你可以关注以下几个信号：**

**Detail Page Views（DPV，详情页浏览量）** ：判断品牌曝光和用户兴趣的重要指标。即使转化率相对较低，较高的 DPV 依然说明这部分流量为品牌带来了有效的曝光。

**间接 SEO 提升** ：指的是达人带来的流量会带动亚马逊站内品牌关键词的搜索，同时增加进入品牌店铺的自然流量。

**New-to-Brand（NTB，新客）** ：指过去12个月内首次购买您品牌的用户。较高的 NTB 占比通常意味着你的活动正在有效触达新的用户。

## **Best Seller Rank（BSR，畅销排名）**

Best Seller Rank（BSR）是亚马逊内部的排名指标，用来衡量某个产品在所属类目中的销售表现。数值越低，排名越靠前。BSR 主要受以下因素影响：

  * 近期销售速度（最关键的因素）

  * 历史销售表现（用于平滑短期波动）

  * 在同类目中相对于其他竞品 ASIN 的表现

需要注意以下几点：

  * **转化质量比流量规模更重要。** 高转化的站外流量有助于提升 BSR，而低转化流量可能导致排名停滞甚至下滑，低质量流量会稀释整体表现。

  * **时间因素非常关键。** BSR 是有时间权重的，短期的销量爆发可能带来暂时的排名提升，而持续稳定的销量才能带来更稳定的排名。

  * **通过归因产生的订单与自然流量或广告带来的订单在权重上是相同的** ，没有任何降低权重或特殊标记，本质上订单就是订单。

  * **类目竞争决定上限。** BSR 是相对指标，竞品的销售速度会直接影响你的排名变化空间，因此保持稳定的销量对于维持排名至关重要。

## **客户生命周期价值（LTV）**

亚马逊归因可以帮助区分新客（New-to-Brand, NTB）和旧客复购，从而更好地理解客户生命周期价值（LTV）。能够带来更高新客占比以及复购行为的渠道（例如 Levanta），通常意味着更强的长期 LTV 表现。

**在 Levanta 中可以重点关注以下 LTV 相关指标：**

  * New-to-Brand 订单数和销售额

  * NTB 订单占比

  * NTB 单笔订单购买件数

**在亚马逊上衡量 LTV 的方式包括：**

  * 复购行为

  * 复购频率

  * 订阅和保留情况

  * 跨 ASIN 复购

 _像 Levanta 这样能够持续带来新客并促进复购的渠道，通常在长期可以带来更稳定、更可持续的 LTV 回报。_

# 了解您的卖家数据看板

Last updated 5 days ago

登录 Levanta 后，您首先看到的就是卖家数据看板（Seller Dashboard）。数据看板可以帮助您快速了解项目的整体表现，并集中展示当前需要关注和处理的重要事项，让您清楚掌握下一步的工作重点。

## **数据看板包含哪些内容？**

### **KPI 核心数据概览**

数据看板会集中展示以下核心指标：

  * 点击量

  * 转化量

  * 销售额

  * 佣金

每项指标都会显示百分比变化和趋势小图，让您无需进入详细报告，也能快速了解近期表现。

其中，百分比变化对比的是最近 30 天与此前 30 天的数据。

### **合作概览**

您可以在合作概览中快速查看日常需要重点关注的数据，包括：

  * 待处理的付费推广

  * 待审核的创作者申请

  * 待处理的寄样申请

  * 当前合作中的创作者数量

  * 已启用的产品数量

  * 已启用的品牌数量

页面同时提供快捷操作按钮，方便您直接从数据看板处理相关事项，无需跳转到其他页面。

    ⚠ 提示： 数据看板中的 Active Creators（活跃创作者）数量，是按卖家账号维度统计的不重复创作者数量
    如果同一位创作者同时与您的多个品牌合作，在数据看板中只会计算 1 次。但当您导出 Active Creators 列表时，系统会列出您旗下各品牌的所有合作关系，因此同一位创作者如果与多个品牌合作，可能会在导出文件中出现多次。
    因此，数据看板与导出文件中的创作者数量可能不同，这是正常情况。

### **热门产品与热门创作者**

您可以直接在数据看板查看**最近 30 天表现最佳的产品和创作者** ，并通过快捷入口进一步查看完整的产品或创作者表现数据。

### **账号设置清单**

数据看板中的账号设置清单会显示您的设置进度，帮助您快速了解哪些步骤已经完成、哪些仍待完成。

设置项目包括：

  * 连接所需的各个站点

  * 启用品牌和产品

  * 连接 Stripe

  * 设置 **Loyalty Bonus Program（忠诚度奖励计划）**

  * 以及其他必要的账号设置

按照清单完成相关设置，可以帮助您更完整地使用 Levanta 的各项功能。

### **帮助与新手引导**

如需帮助，您可以直接通过数据看板：

  * 通过邮件或视频会议联系您的 **CSM（客户成功经理）**

  * 联系 **General Support（客服支持）**

  * 浏览 **Knowledge Hub（知识库）**

  * 查看平台内的新手引导视频

无需离开数据看板，即可快速获取所需帮助。

### **新账号操作指引**

如果您刚开始设置 Levanta 账号，数据看板会根据当前的账号状态显示相应的**操作提示和下一步建议** ，而不是仅显示空白页面。

例如，系统可能会引导您寻找合适的创作者，帮助您更快完成账号设置并开始运营。

# Seller 常见问题（FAQ）

Last updated 5 months ago

以下为 Levanta 平台卖家端的常见问题汇总。

**问：如何联系已经加入我项目的创作者们？**

答： 请查看下方的 [_Contacting and Activating Affiliates_](https://www.notion.so/For-Brands-Knowledge-Hub-c618f9245b3c4f7cbc3ded8f731503f4?pvs=21) 相关说明。

**问：没有创作者主动选择我的项目，我该如何吸引他们加入我的联盟计划？**

答： 建立一个成功的联盟项目需要时间和持续投入。Levanta 提供 SaaS 工具帮助您搭建亚马逊联盟项目，并通过创作者市场帮助卖家与推广者建立合作。

但需要注意的是，成功的联盟项目通常需要主动进行推广者招募。我们强烈建议您投入资源进行联盟招募，主动吸引合作伙伴加入您的 Levanta 项目。

您可以在 Partnerships 页面获取专属邀请注册链接，邀请合作伙伴加入。

**问：Brand Referral Bonus（品牌推荐奖励，BRB）是否适用于美国以外的亚马逊站点？**

答：目前 BRB 仅适用于 [_Amazon.com_](http://Amazon.com)（美国站）。

**问：如何领取 Brand Referral Bonus（BRB）？**

答：您需要先在 Amazon 官方页面注册 BRB 计划：[ _https://sell.amazon.com/blog/brand-referral-bonus_](https://sell.amazon.com/blog/brand-referral-bonus)

通过 Levanta 推动的销售将自动计入您的 Brand Referral Bonus。您可以在 Levanta 的 Dashboard中查看 BRB 数据。

**问：如何连接多个 Amazon 账号？**

答：进入 Settings → Connections → Add Amazon Connection，即可绑定多个 Amazon 账号。

**问** ：**我确认今天已经有流量/销售产生，为什么在 Levanta 里看不到？**

答：当记录到前10 次点击后，您将开始看到流量数据。当产生第一笔销售后，您将开始看到转化数据。亚马逊归因数据存在约 24 小时延迟，因此流量和转化最多可能延迟 24 小时显示。

**问** ：**产生新转化后，我什么时候需要支付佣金？**

答**：** 佣金发票将在转化发生后的次月前几天生成。

例如：如果 Creator 在 2 月 12 日产生佣金，您将在 3 月 1 日至 3 日之间收到该笔佣金发票。Levanta 会在您收到发票后的 30 天内，将佣金支付给 Creator。

**问：如果商品后续被退货，已经支付的佣金怎么办？**

答**：** Levanta 会追踪退货及其他转化被撤销的情况。

  * 若转化在发票发送后 30 天内被撤销，我们将在下一期发票中进行调整（抵扣多付佣金）。

  * 若发票发送超过 30 天，该发票内的转化将被视为锁定（locked），不再进行调整。

**问：如何查看单笔转化数据？**

答**：** 目前您可以在报表中查看汇总数据。由于亚马逊归因 API 提供的数据维度有限，暂时无法提供更细致的单笔转化数据。

**问** ：**是否可以在平台外向 Creator 支付佣金？**

答**：** 对于在 Levanta 平台内追踪的转化，我们不支持平台外支付佣金。

**问** ：**如何创建自定义报表？**

答**：** 目前暂不支持自定义报表功能。如您有特定报表需求，请通过应用内聊天联系客户成功团队提出建议。

# 了解您的通知提醒（卖家）

Last updated 9 days ago

通过及时查看 Levanta 通知，可以帮助您掌握创作者合作、推广活动、付款及项目表现等重要动态。以下为卖家可能收到的主要通知类型及相关说明。

## 🔎**筛选通知**

您可以使用 **Notifications（通知）** 面板中的筛选功能，快速找到需要查看的通知，无需逐条浏览。

点击面板顶部的**筛选图标** ，可按以下条件筛选：

  * **紧急程度** ：按通知的优先级筛选

  * **通知类别** ：例如 Partnerships（合作）、Payments（付款）、Digest（汇总）、Commissions（佣金）或 Teams（团队）

  * **站点** ：按已连接的特定站点筛选

点击 **Clear All（全部清除）** 可一次性清除所有通知；点击**设置** 图标，可管理您的通知偏好。

## **合作相关通知**

### **收到合作申请**

有新的创作者申请加入您的品牌合作项目。

**您可以：** 前往 Dashboard 中的 **Partnerships（合作）** 页面查看申请，并选择批准或拒绝。

### **创作者已接受邀请**

创作者已接受您发送的合作邀请。

**您可以：** 关注该创作者后续的推广表现，并考虑向其提供免费样品或发送 **CPC 合作邀请** ，进一步推动合作。

## 💳**付款相关通知**

### **Paid Placement 退款已处理**

当您的**付费推广** 合同退款已处理时，您会收到此通知。

**请注意：** 退款通常需要 **5–10 个工作日** 退回至您的银行卡。

### **Paid Placement 托管付款失败**

当 Paid Placement 的托管款项支付失败时，您会收到此通知。

**您需要：** 尽快重新完成付款，以免影响 Paid Placement 推广活动的正常进行。

### **添加付款方式提醒**

如果您的账号尚未设置付款方式，系统将**每周发送一次提醒** 。

**您需要：** 前往 **Billing Settings（账单设置）** 添加付款方式，以避免影响创作者佣金付款或平台功能的正常使用。

## 💰**佣金相关通知**

### **CPC 预算额度提醒**

当 CPC按点击付费推广活动的预算使用达到以下比例时，系统会发送通知：

  * 50%

  * 75%

  * 100%

**您可以：** 查看当前推广表现，并根据实际情况调整预算或推广策略。

### **Creator Connections 活动即将到期**

当正在进行的 **Creator Connections** 活动即将到期时，系统会发送提醒，例如“将在 2 天后到期”。

**您可以：** 查看活动详情。如需继续运行该活动，请及时延长或续期，避免活动中断。

## 📬**每日汇总**

### **每日摘要**

系统会通过每日邮件汇总重要的平台动态，包括：

  * 新的创作者申请

  * 创作者接受合作邀请

  * 推广活动动态

  * 预算状态更新

您可以通过每日摘要快速掌握项目表现及创作者合作进展。

### **产品已归档**

如果一个或多个已启用的产品无法再通过您的亚马逊连接获取，Levanta 会自动将这些产品归档。

此前，此类产品仅会显示 **Not Found（未找到）** 状态，现在系统会自动进行归档处理。

**您需要：** 前往 Amazon 检查相关商品是否仍正常在售。如果商品已恢复正常，可返回 Levanta 将其**取消归档（Unarchive）** 。系统每天都会检查产品状态。

## 👥**团队相关通知**

Teams（团队）类别主要用于账号管理及团队成员协作。具体通知内容可能有所不同，常见通知包括：

  * **新团队成员邀请** ：管理员邀请新成员加入品牌的 Levanta 账号时发送

  * **邀请已接受** ：受邀成员成功加入并激活账号时发送

  * **角色与权限变更** ：账号成员的角色或权限发生变化时发送，例如从 Member 调整为 Admin

  * **安全与登录提醒** ：出现异常登录尝试或账号安全设置需要处理时发送的高优先级通知

  * **平台访问权限提醒** ：当某些必要的账号权限或连接权限缺失时发送，例如 Levanta Admin Panel 或 Seller Central 集成所需权限

## 🔔**其他常见通知**

### **Amazon Ads 连接已断开**

当您的 Amazon Ads 连接断开时，系统会立即发送通知。

**请注意：** 您有 **7 天的宽限期** 重新完成连接。超过期限后，相关推广活动将暂停，同时 CPC 功能也会被停用。

### **品牌连接已断开**

当品牌与 Amazon 的连接断开时，例如亚马逊归因连接失效，系统会发送通知。

**请注意：** 系统提供 **7 天的宽限期** 。如果未及时恢复连接，创作者对该品牌的访问权限可能会被停用，同时品牌在平台上的展示也会暂停。

### **Creator Connections 开通提醒**

如果您的账号已启用 **Creator Connections** ，但尚未将任何品牌连接至该功能，系统将**每周发送一次提醒** 。

**您需要：** 完成 Creator Connections 的品牌连接设置。完成后即可开始邀请创作者并接收合作申请。

### **套餐取消提醒**

如果您的套餐已安排取消，系统会在正式取消前多次发送提醒。

**请注意：** 您可以在账号停用前利用这段时间更新付款信息或更换套餐。

## 📌**在哪里查看通知？**

所有通知都会通过**电子邮件** 发送，同时也会显示在您的Levanta 控制面板中。

建议及时查看相关通知，以便及时处理账号、付款、推广活动及创作者合作事项，确保您的 Levanta 项目正常运行。

# 亚马逊归因集成

Last updated 5 months ago

**亚马逊归因集成：故障排查与常见问题**

如果您在 **Levanta** 中连接 **亚马逊 Seller Central 账户** 或访问归因数据时遇到问题，本指南将帮助您了解常见问题及其解决方法。

## **为什么无法连接我的 Seller Central 账户？**

请确认以下事项：

✅ 您使用的是与要连接的 Seller Central 账户 关联的正确邮箱地址。

✅ 您是该 Seller Central 账户的主用户（Primary / Top-level User）。

✅ 如果您是 次级用户（Secondary User），请确认已获得正确的权限（详见下方说明）。

✅ 您的品牌已完成 Brand Registry（品牌注册），并且拥有 亚马逊归因的访问权限。

## **为什么 Levanta 显示 “Brand Does Not Have Attribution Access”？**

如果在 Levanta 中看到此错误提示，通常表示：

  * 您的 Seller Central 账户权限尚未完全设置

  * 或您的品牌尚未正确加入 亚马逊归因项目

**解决方法：**

**联系亚马逊卖家支持**

请联系亚马逊卖家支持并说明：

  * 为您的品牌开启 Amazon Attribution API 访问权限

  * 您正在与 第三方合作伙伴（Levanta） 集成，该平台需要归因数据

  * 如需进一步支持，也可以联系：[ _ads-api-support@amazon.com_](mailto:ads-api-support@amazon.com)

## **验证品牌注册状态**

请确认：

  * 您的品牌已经加入 Brand Registry（品牌注册）

  * 您的 Seller Central 账户已正确关联该品牌

**等待同步时间**

如果您刚刚更新权限，获得访问权限或加入归因，请等待 24–48 小时，让数据同步到 Levanta。

📌 **注意：** Levanta 无法直接修改您的亚马逊账户设置。所有权限更新都必须通过 Seller Central 或 亚马逊 Seller Support 完成。

## **次级用户如何获得 Brand Referral Bonus 或报告访问权限？**

只有主用户授予权限的情况下，次级用户才可以访问Brand Referral Bonus（BRB）注册或相关数据报告。该权限必须在 亚马逊 Seller Central 中设置，而不是在 Levanta 中。

### **在 Seller Central 中授予权限**

  1. 使用 **主用户账户** 登录 **Seller Central**

  2. 前往**Settings → User Permissions → Manage Permissions**

  3. 向下滚动到 **Performance** 部分

  4. 在 **Brand Referral Bonus** 下选择权限：

  * **View** ：允许下载报告

  * **View & Edit**：允许注册 BRB

📌**注意：** 如果没有这些权限，次级用户将无法访问或管理 Brand Referral Bonus 功能。

# 管理品牌与产品

Last updated 9 days ago

本指南将引导您了解如何在 Levanta 平台中管理品牌、产品和店铺页面的关键操作。

## **激活您的品牌**

在完成 [**_品牌详情页面_**](https://knowledge.levanta.io/articles/7948411124-general-account-setup) 的填写后，请按照以下步骤操作，使您的品牌对创作者可见：

**操作步骤：**

  1. 在左侧菜单中前往 **Brands**

  2. 点击您想要激活的品牌

  3. 点击 **Activate** 按钮，启动品牌激活设置

  4. **审核联盟计划条款（Affiliate Program Terms）**

     * 您可以使用 Levanta 的默认联盟条款或选择 **Use custom terms** ，链接至您自行托管的条款页面

  5. 确认地区激活提示（Geo-activation notice）

  6. （可选）点击 **Advanced Options** ，开启 **自动接受创作者申请（Auto-Accept Creator Applications）功能。**

## **新产品在 Levanta 中的显示位置**

当新产品添加到您的店铺时，它们不一定会立即显示在已激活产品列表中。根据您的设置，新产品可能会出现以下两种情况之一：

  1. 显示在**已归档产品（Archived Products）** 中，您需要**手动取消归档（Unarchive）** ， 产品才会变为可见并激活，或者：

  2. 需要通过 CSV **手动导入** ，如果系统未自动同步新产品，您需要使用 **Update Products via CSV** 功能进行手动导入。

## **手动导入产品**

如果新产品未显示在 **Archived Products** 中，您可以按照以下步骤手动导入：

  1. 前往 **Products**

  2. 点击页面右上角的 **Update Products via CSV**

  3. 上传更新后的 CSV 文件，将新产品同步至产品目录

  4. 导入完成后，新产品将显示在 **已激活产品列表（Active Product List）** 中

## **停用品牌**

停用品牌将会产生以下影响：

  * 取消所有正在进行的创作者合作关系

  * 停用该品牌下的所有产品

  * 归档现有的联盟链接

  * 从创作者市场中移除品牌的可见性

**停用步骤:**

  1. 前往 **Brands**

  2. 点击您想要停用的品牌

  3. 滚动至品牌详情页面底部

  4. 点击 **Deactivate Brand**

     ⚠注意事项：此操作将影响所有已关联的品牌、产品及合作关系，请谨慎使用。

## **归档品牌**

归档功能可将**不活跃或不再使用的品牌** （尤其是从亚马逊同步进来的品牌）从可见列表中隐藏。

归档步骤:

  1. 前往 **Brands**

  2. 选择您想要归档的品牌（可多选）

  3. 点击 **Actions → Archive Brand**

## **如何归档与取消归档产品**

Levanta 允许您归档不再希望主动显示或管理的产品，并在需要时同样轻松地取消归档。

### **取消归档产品：**

  1. 前往 **Products** 页面，并滚动至产品列表底部

  2. 点击 **See Archived Products**

  3. 找到需要恢复的已归档产品

  4. 勾选产品，并在 **Actions** 中选择 **Unarchive**

## **归档产品**

  1. 在左侧菜单中前往 **Products**

  2. 找到您想要归档的产品

  3. 勾选产品旁的复选框，并选择 **Actions → Archive Products**

## **激活店铺页面**

前往 **Brands** 并选择您要管理的品牌。在 **Brand Profile** 区域，点击齿轮图标。选择 [**_Manage Storefronts URL_**](https://knowledge.levanta.io/articles/7948411124-general-account-setup) 进入店铺页面设置。系统将显示从亚马逊同步的所有店铺页面（Storefronts）

在此页面中，您可以：

  * 切换 开/关 以设置某个页面是否对创作者可用。

  * 切换 开/关 以将特定页面设为您默认的主要店铺链接。

## 39. 卖家 API 详细说明

**Source:** <https://knowledge.levanta.io/articles/4413439870-api>

# 卖家 API 详细说明

Last updated 9 days ago

## **前置条件**

如需使用卖家 API，请先完成以下设置：

  1. 拥有 Levanta 卖家账号的访问权限，可通过以下任一方式获得：

     * 注册 Levanta 卖家账号 [_app.levanta.io/auth/sign-up_](http://app.levanta.io/auth/sign-up)

     * 由团队成员邀请您加入现有卖家账号

  2. 生成 API 密钥以获取 API 访问权限 [/seller/settings/api](https://app.levanta.io/seller/settings/api)

     * 您需要使用具有管理员权限的账号登录后才能生成 API Key

     * 进入 Settings → API，点击绿色的 Generate API Key（生成 API 密钥） 按钮即可

## **API 测试**

您可以通过 **Swagger API 文档** 测试所有 API 接口，并查看请求与返回结果 请查看[ _这里_](https://api-docs.levanta.io/introduction)

**API 身份验证**

所有 Seller API 请求都必须使用 **API Key** 进行身份验证。

使用具有管理员权限的账号登录后，可以前往 **Settings → API** 查看您的 API Key。

发送请求时，请在 Authorization Header 中使用：

    Bearer <API-Key>

API 请求地址：<https://app.levanta.io/api/seller/v1>

## **分页机制**

对于返回多条数据的 API 接口，Levanta 使用基于 **Cursor（游标）** 的分页方式。

首次请求时，无需填写 cursor 参数。每次请求后，API 返回的 JSON 数据中都会包含一个 cursor 值。

如需获取下一页数据，请将上一次返回的 cursor 值传入下一次请求的 cursor 参数中，并重复此操作，直到获取全部数据。

当没有更多数据时，返回的 cursor 将为 null。

## **API 接口文档**

目前 Seller API 提供以下 GET Endpoint：

  * /creators/active

  * /brands/{brand_id}

  * /brands

  * /reports

  * /reports/brb

  * /reports/clicks

  * /products
